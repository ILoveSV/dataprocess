# 时域信号处理与可视化工具 v1.0

## 📋 项目概述

一款专业的时域信号处理与可视化GUI程序，支持多种文件格式、丰富的相似性度量方法、频域分析和矩阵转换功能。

## 🚀 快速启动

### 方式一：双击启动（推荐）
直接双击 `start.bat` 文件即可启动程序。

### 方式二：命令行启动
```bash
cd signal_processor_app
python main.py
```

### 方式三：Python导入
```python
from main import main
main()
```

## 📊 功能说明

### Tab 1: 时域相似性处理

| 11 | 结构相似性(SSIM) | 图像结构相似度 |

## 🛠️ 使用步骤

### 时域相似性分析 (Tab 1)
1. 点击"浏览..."选择A状态文件和B状态文件
2. 选择需要分析的通道（多通道数据时）
3. 在方法列表中选择一种或多种相似性度量方法
4. 点击"计算相似性"按钮
5. 在可视化下拉菜单中选择图表类型，点击"可视化"
6. 点击"保存图像"或"保存结果数据"导出结果

### 频域相似性分析 (Tab 2)
1. 加载A状态文件和B状态文件
2. 设置采样率（Fs），如果文件头部包含采样率信息会自动读取
3. 选择频域相似性方法
4. 点击"计算频域相似性"
5. 可视化频谱对比结果

### 矩阵转换与可视化 (Tab 3)
1. 加载时域数据文件
2. 选择通道和采样率
3. 选择一种或多种矩阵转换方法
4. 点击"生成矩阵"
5. 选择可视化方式，点击"可视化"
6. 可将矩阵保存为 .npy, .csv 或 .mat 格式
