# 导师建议原始数据补全分析报告

## 1. 结论先行

**整段原始高频数据增加了一个此前三短窗无法得到的实质结果：RUN链会提高跨通道高频相干。** RUN相对本地STOP时，80--200 kHz通道对整段相干估计在8/8个日期-摆位-探测器层级同向增加，层级中位差为0.011721，Wilcoxon p=0.0078，方法族FDR=0.0134。进一步拆成8个历元后，22/24个文件配对、7/8个独立层级的历元中位数仍为正；历元优胜比例中位数为1.000。因此它是有用候选，但存在一个TC2摆位的时间局部反向，不能写成无条件稳定。

使用全部整段相干与相位候选特征，RUN/STOP整组留一平衡准确率为0.667，499次组内标签置换p=0.068。进一步只保留预定义80--200 kHz相干中位数及其历元中位数后，平衡准确率为0.750，p=0.010；STOP召回率1.000，RUN召回率0.500。分探测器后，TC1为0.958、p=0.008，TC2为0.750、p=0.078；TC2需合并旧时域和完整高频特征才达到0.833、p=0.018。因此现有数据支持“按探测器建立的运行链状态探索性识别”，不支持一套跨探测器通用规则。80--200 kHz频带是在本研究证据形成过程中确定的，必须在新批次锁定参数外部验证；更不能把RUN标签改写为水流。

**载波结论没有改变。** 4/8/12 kHz谐波梳状模板仅正确5/12，设定载波得分相对其他模板的中位优势为-0.110 dB；不能识别载波档位。

**30/50 Hz与水流识别仍没有阳性。** 整段原始相干没有改善30/50分类；5月360文件的跨距离结果也未提供可部署的水流标签。

## 2. 主实验整段高频

- 49个文件各从完整稳定区间均匀抽取96个40.96 ms原始窗口，不再由三个1 s片段代表整段。
- 每文件动态使用健康通道；TC1、TC2仍分别相对本机背景和STOP分析。
- 双相干在49/49文件超过19次相位代理；历元峰重复比例中位数0.875。它说明系统的非线性混频比三短窗显示得更持续，但背景和STOP同样存在，因此不具备水流特异性。

## 3. 主动脉冲与弛豫

- 完整处理188个脉冲工况、533个状态转换。
- 每个脉冲工况独立判断坏道，健康通道数范围8--12。
- 精确重复频率相对附近伪频率名义p不超过0.05的工况：39/188；跨188工况方法族FDR后为0/188。每组99个伪周期使最小p为0.01，因此全局FDR结果是保守边界，不单独用于宣称周期响应不存在。三段波形中位相关至少0.5的工况：147/188。
- 方波电平、瞬时边沿和32档指数核模板联合比较后，最佳模板为指数迟豫的工况182/188；但|模板相关|至少0.25的仅1/188。
- 同时通过周期特异、三段重复、模板相关、事件SNR、AICc、R2、时间常数可辨识和跨段tau稳定门槛的弛豫：0/533。
- 电压依赖在方法族FDR后达到|rho|>=0.8的统计关联：0/20；必须结合实际相关幅值和方向解释，不能自动记为正向剂量响应。

## 4. 严格投影MEMD

- 已完成真正的多通道投影包络与共同IMF提取，不再使用逐通道EMD频带对齐代替MEMD。
- 16/24方向下主导中心频率差的中位数为0.0252 Hz，90%分位为0.0559 Hz。
- 工况对照中通过方法族FDR的参数化特征为0/24。详细阴性或阳性条目见`PROJECTION_MEMD_SIGNIFICANCE.csv`。

## 5. 2026-05-12跨距离批次

- 360个连续短文件按9个距离-工况运行处理，未把相邻文件当作独立重复。
- 360个文件逐文件动态判断坏道，健康通道数范围10--11。
- 3.1 s固定周期在5种信号代理乘9个运行组的红噪声全频搜索中，族错误率校正后阳性0/45。
- 0/30/50三分类跨距离平衡准确率0.556，置换p=0.152；30/50二分类为0.500，p=0.747。
- 与6月17日相同方向的频带-工况组合为10/10。两个批次均表现为20--80 kHz轻微下降、80--200 kHz轻微上升，但30 Hz和50 Hz方向相同；这支持运行链宽频带重分配的跨批次复现，不支持30/50特异识别，也不能用文件数量制造显著性。

## 6. 旧阴极保护数据边界

8月11日两批已经按完整精确归档做过动态坏道、固定频率、手动开关、边沿、剂量与重复性检查。本轮继续单独保留：旧电极间距约1 cm且没有同步电流波形，不能把它们混入水流识别或最终阴极保护检出结论。
