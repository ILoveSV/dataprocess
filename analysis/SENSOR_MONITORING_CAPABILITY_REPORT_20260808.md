# 传感器监测能力阶段报告

**版本日期：** 2026-08-08  
**证据范围：** 2026-07-31 工况拆分实验、2026-08-06 双探测器交叉校准与 VFD 载波实验，以及已有 COMSOL 结果  
**报告对象：** TC1、TC2 探测器及其采集、布线、现场环境和数据分析构成的完整监测系统

## 1. 执行结论

依据目前证据，系统已经证明具有以下能力：

1. 能稳定检测 VFD-电机-泵运行链引起的强高频变化。RUN 相对 STOP 在 1-200 kHz 的多个频带内产生全健康通道一致的增强，典型增益约 4-23 dB，并伴随大量窄谱线。
2. 在约一分钟的平稳记录内，如果目标频率事先已知且相位、频率保持稳定，系统可通过平均和相干拟合识别远低于原始宽带噪声的周期成分。对 0.323 Hz 固定目标，背景拟合得到的单通道经验 95% 虚假周期幅值为 3.49 uV 峰值。
3. TC1 与 TC2 均能监测低频均值、低频波动包络、宽带能量和高频残差，但两台仪器的高频绝对响应存在约 2-4.5 dB 的系统差异，不能直接合并绝对幅值。
4. 当前未检出与约 3.1 s 水力脉动同步、并能跨通道、跨探测器、跨摆位和跨载波设置复现的电信号。这表示水流电信号低于当前系统在本次距离和现场噪声下的可靠检出能力，不表示物理信号严格为零。

目前不能从已有实验得到以下参数：

- 不能给出以 V/m 表示的最小可检电场。
- 不能给出以 A 表示的最小可检放电或阴极保护电流。
- 不能给出通用最大探测距离。
- 不能证明系统能够测量稳定直流场。
- 不能把高频干扰唯一归因于 VFD 功率器件；当前只能归因于 VFD-电机-电缆-泵负载组成的运行链。

这些限制的根本原因是尚未测得探测器的外场传递函数，即不同频率下“外部电场强度到输出电压”的增益与相位。

## 2. 证据基础与有效通道

### 2.1 数据条件

- TDMS 采样率为 400 kHz，采样间隔为 2.5 us。
- 数字采样对应的理论奈奎斯特频率为 200 kHz；这只是采集上限，不等同于传感器本体已经标定到 200 kHz。
- 频谱使用 262144 点 FFT，单个频谱窗约 0.655 s，频率栅格约为 1.526 Hz；每个文件取约 20%、50%、80% 位置的三个频谱窗并取中位数，以降低偶发异常影响。
- 低频与能量包络以 0.1 s 为一个分析块，输出采样率为 10 Hz。
- 稳态分析通常去除起始 15 s 和末尾 5 s，以减少启停过程及文件边缘影响。

### 2.2 通道健康状态

2026-08-06 的 32 个 TDMS 文件中确认了三个持续坏道：

| 探测器 | 固定排除通道 | 主要异常 |
|---|---:|---|
| TC1 | 12 | 1-20 kHz 噪声持续比正常通道高约 20 dB |
| TC2 | 8 | 直流工作点异常，低频漂移极强 |
| TC2 | 11 | 1-20 kHz 噪声持续比正常通道高约 17 dB |

因此，当前有效通道数为 TC1 11 路、TC2 10 路。后续所有能力判断都应固定排除上述通道。

健康通道在本批数据中的平均工作点约为 5.00 V，未出现非有限值和明显削顶。这个结果只能说明本批工况没有把采集输入推到明显饱和，不能替代完整的线性范围标定。

## 3. 各类指标的物理和统计含义

### 3.1 原始宽带噪声

原始宽带噪声是每个健康通道全部原始采样点相对自身均值的标准差：

\[
\sigma_{\mathrm{raw}}=\sqrt{\frac{1}{N}\sum_{n=1}^{N}(x_n-\bar{x})^2}.
\]

2026-08-06 全部健康通道和工况的结果为：

| 探测器 | 中位数 | 10%-90% 范围 | 总范围 |
|---|---:|---:|---:|
| TC1 | 4.038 mV RMS | 3.244-4.370 mV | 3.102-5.136 mV |
| TC2 | 4.211 mV RMS | 3.218-4.745 mV | 3.211-4.842 mV |

这个约 4 mV 包含传感器本底、模拟前端、采集卡、环境电磁信号和真实现场谱线的共同贡献。它不是“最小可检电压”，也不能直接解释成随机白噪声。

一个稳定窄带信号即使远小于 4 mV，仍可能通过带限、平均或相干积累被检出。反过来，一个与背景同形、频率未知、持续时间很短的信号，即使瞬时幅值超过几微伏，也未必能稳定识别。

### 3.2 0.1 s 慢变均值

慢变均值是每 0.1 s 内约 40000 个原始采样点的平均值：

\[
m_k=\frac{1}{40000}\sum_{n\in k}x_n.
\]

它主要保留秒级和亚秒级的直接电压变化，并抑制大量高频噪声。10 Hz 的输出采样率对应 5 Hz 奈奎斯特频率，因此适合研究水流脉动、周期通断、慢变放电和极化恢复；但目前专门验证的目标带仅为 0.05-0.70 Hz。

在六组 2026-08-06 背景文件中，对慢变均值拟合“常数项+线性趋势+0.323 Hz 正余弦”后，剩余波动的中位数为 16.44 uV RMS，95% 分位为 22.17 uV RMS。这比 4 mV 原始噪声小很多，主要来自 0.1 s 内大量采样点的平均。

### 3.3 虚假周期幅值

“虚假周期幅值”不是设备产生的真实周期信号，而是把纯背景强制拟合到某个目标频率时，噪声和漂移偶然形成的表观正弦幅值。

对预先指定的 3.10 s 周期，采用模型：

\[
x(t)=c_0+c_1t+a\sin(2\pi f_0t)+b\cos(2\pi f_0t)+\varepsilon(t),
\]

其中 \(f_0=1/3.10=0.323\ \mathrm{Hz}\)，拟合周期峰值幅度为：

\[
A_{\mathrm{peak}}=\sqrt{a^2+b^2}.
\]

在六组背景、63 个“文件-健康通道”组合上的结果为：

| 分位数 | 背景表观周期峰值 |
|---:|---:|
| 50% | 1.65 uV peak |
| 90% | 2.72 uV peak |
| 95% | 3.49 uV peak |
| 99% | 3.89 uV peak |
| 最大值 | 4.07 uV peak |

因此，3.49 uV peak 可视为当前记录长度、当前环境和固定 0.323 Hz 单目标检验下的经验 95% 假阳性门槛。它对应约 2.47 uV RMS 的正弦量。

这个门槛有四个严格限制：

1. 目标频率必须事先指定，不能看完数据后挑最高峰。
2. 信号需要在约一分钟记录中保持频率和相位基本稳定。
3. 该门槛是单通道、单频率门槛；同时搜索很多频率和通道会提高总假阳性率。
4. 它是探测器输出端电压门槛，不是外部电场门槛。

为适应多通道、多次重复和现场非平稳性，建议把 5-10 uV peak 作为后续已知低频周期实验的工程候选门槛，同时要求多数健康通道支持、ABAB 重复成立。该数值是保守判据建议，不是已经完成标准标定的正式检出限。

### 3.4 宽带 RMS、低频 RMS 和高频残差 RMS

每个 0.1 s 块还计算以下能量包络：

- `broadband_rms`：块内全部原始采样点的标准差，反映该时段内总体交流能量，通常容易受高频干扰支配。
- `subkhz_rms`：先计算每 1 ms 的均值，再计算这些均值在 0.1 s 内的标准差，主要表征约 1 kHz 以下波动，但它不是理想砖墙低通滤波器。
- `fast_residual_rms`：原始数据减去相应 1 ms 均值后的 RMS，主要表征约 1 kHz 以上的快速波动，也不是严格频带滤波。
- `difference_rms`：相邻采样差分的 RMS，对越高频率的变化越敏感，主要用于坏道和快速噪声诊断。

这些 RMS 随时间形成 10 Hz 包络。如果高频载波的强度被 0.323 Hz 水力周期调制，即使原始高频谱线本身不移动，也可能在 `broadband_rms` 或 `fast_residual_rms` 的 0.323 Hz 包络中被发现。现有实验已经检验了这种可能，但没有得到跨探测器复现结果。

### 3.5 功率谱密度和频带功率

功率谱密度 PSD 描述输出电压方差如何分布在频率轴上，单位为 V^2/Hz。某一频带的功率为：

\[
P_B=\int_{f_1}^{f_2}S_{xx}(f)\,df,
\]

其平方根 \(\sqrt{P_B}\) 才是该频带对应的 RMS 电压。当前固定使用五个频带：

| 频带 | 主要用途 |
|---|---|
| 5-100 Hz | 工频、低频机械/电源成分及其附近变化 |
| 100 Hz-1 kHz | 低阶谐波和中低频电气噪声 |
| 1-20 kHz | VFD 设定载波候选区、开关谐波和设备噪声 |
| 20-80 kHz | 高频线谱密集区 |
| 80-200 kHz | 更高频运行干扰；接近奈奎斯特上限，需警惕模拟带宽和混叠 |

工况相对背景的频带增益定义为：

\[
\Delta L_B=10\log_{10}\frac{P_{B,\mathrm{condition}}}{P_{B,\mathrm{background}}}
=20\log_{10}\frac{V_{B,\mathrm{RMS,condition}}}{V_{B,\mathrm{RMS,background}}}.
\]

常见 dB 变化可解释为：

| 增益 | 功率比 | 频带 RMS 比 |
|---:|---:|---:|
| +1 dB | 1.26 | 1.12 |
| +2 dB | 1.58 | 1.26 |
| +3 dB | 2.00 | 1.41 |
| +10 dB | 10.0 | 3.16 |
| +20 dB | 100 | 10.0 |

频带功率适合判断“某一段频率的总能量是否增加”，但不能说明增加来自哪一条谱线，也不能单独证明信号源的物理机制。

当前三个频谱窗能够代表三个时刻的稳定频谱，却不等于连续覆盖整段记录。因此它适合稳定谱线和稳定频带能量比较，可能遗漏只在三个窗口之外发生的短促瞬态；瞬态问题应直接回到原始时序或使用连续短时频谱分析。

### 3.6 窄谱线

窄谱线是集中在很少频率栅格内的功率峰。它适合检测稳定振荡、时钟、开关谐波和电源纹波，但容易受频率漂移、采样时钟、混叠和环境设备影响。

2026-08-06 RUN 数据中的可重复候选包括约 53.3-53.7 kHz、122-124 kHz、145.7-145.9 kHz、152.0 kHz 和 159.32 kHz。部分谱线相对纯背景增强约 3-14 dB，其中约 152.0 kHz 在 TC1 的六个 RUN 工况中均明显出现，约 145.8 kHz 在 TC2 的六个 RUN 工况中均明显出现。

这些谱线可作为本批实验的 RUN 状态特征，但不是跨日期、跨仪器的通用固有频率。改变 4/8/12 kHz 设定后，没有得到随设定稳定迁移的对应主峰，因此不能把这些高频线直接称为“设定载波频率”。

## 4. 当前可量化的系统能力

| 能力项目 | 当前量化结果 | 正确解释 |
|---|---:|---|
| 原始输出宽带波动 | 约 4 mV RMS | 单点总噪声/现场波动，不是最小可检信号 |
| 0.1 s 慢变均值残差 | 中位 16.44 uV RMS，95% 为 22.17 uV RMS | 经过 40000 点平均后的低频时间序列波动 |
| 固定 0.323 Hz 背景虚假幅值 | 95% 为 3.49 uV peak | 约一分钟、单频率相干拟合的经验假阳性门槛 |
| 低频周期工程候选判据 | 5-10 uV peak | 建议值，需多通道、重复和对照共同满足 |
| 高频同文件估计稳定性 | 宽带/高频 RMS 半程差通常小于 0.01 dB | 只表示平稳文件内平均估计精密，不代表现场检出限 |
| 高频成对工况候选判据 | 至少约 2 dB，且多数健康通道同向 | 当前建议，用于同场相邻 ABAB 对比 |
| VFD RUN 实测变化 | 多频带约 4-23 dB，健康通道 100% 同向 | 已稳定检出的强设备运行信号 |
| 跨时段背景变化 | 低频带约 0.36-0.90 dB；高频带约 1.62-10.95 dB | 不同时间的绝对背景不可直接当成同一基准 |

平稳文件内非常小的 dB 波动来自大量样本平均，只说明统计估计精密。实际工况识别受环境变化、设备状态、探测器差异和布线变化支配，因此实用门槛必须高于这个数学估计误差。

## 5. 重复性、跨时段稳定性与仪器差异

六组背景文件按探测器分别统计，三个背景时段的通道中位频带功率范围为：

| 探测器 | 5-100 Hz | 100 Hz-1 kHz | 1-20 kHz | 20-80 kHz | 80-200 kHz |
|---|---:|---:|---:|---:|---:|
| TC1 | 0.90 dB | 0.65 dB | 10.95 dB | 4.83 dB | 4.31 dB |
| TC2 | 0.36 dB | 0.73 dB | 6.15 dB | 3.31 dB | 1.63 dB |

这说明：

1. 低频频带的跨时段背景相对稳定，但仍不是零漂移。
2. 高频背景受现场窄谱线和设备状态影响很大，尤其是 1-20 kHz。
3. 跨日期使用固定绝对阈值容易误判；最可靠的是同一探测器、同一位置、相邻时间的背景-激励 ABAB 对照。
4. TC1 高频绝对功率通常比 TC2 高约 2-4.5 dB。该差异可能包含传感器增益、模拟前端和个体噪声差异，不能用简单合并平均消除。

## 6. 当前能够检测、可能检测和尚不能证明的信号

### 6.1 已被实验直接证明可检测

| 信号类型 | 当前结论 |
|---|---|
| 强高频窄谱线群 | 可检测；VFD-电机-泵 RUN 已在 1-200 kHz 多频带和多数谱线中复现 |
| 高频总能量变化 | 可检测；RUN 相对 STOP 的 4-23 dB 增强远高于同文件估计误差 |
| 强设备运行状态 | 可将强高频 RUN 与低高频状态大致区分 |
| 持续坏道和异常工作点 | 可通过均值、标准差、频带功率和差分指标稳定识别 |

### 6.2 在满足条件时理论上可检测

| 信号类型 | 必要条件 |
|---|---|
| 已知频率的低频周期电压 | 频率和相位在约一分钟内稳定，输出峰值达到约 5-10 uV，并在多通道和重复试验中出现 |
| 周期通断或伪随机调制信号 | 有同步参考序列，可采用互相关或匹配滤波积累 |
| 高频载波被低频调制 | 高频能量足够，并在 RMS 包络中形成稳定、可重复的低频周期 |
| 50/100 Hz 电源纹波 | 谱线超过本地背景并能通过电源开关或负载对照复现；仅看到 50 Hz 不能完成来源归因 |
| 短时脉冲和放电瞬态 | 原始采样在时间分辨率上具备记录条件，但脉冲检出阈值、模拟带宽和传感器瞬态响应尚未标定 |
| 0.7-5 Hz 变化 | 10 Hz 包络在数字上可以表示，但当前没有专门的注入实验验证灵敏度 |
| 低于 0.05 Hz 的慢变化 | 需要更长记录和严格零漂控制；当前一分钟级记录不足以把它与漂移可靠分开 |

### 6.3 当前尚不能证明可检测或识别

| 信号类型/任务 | 原因 |
|---|---|
| 稳定直流外电场 | 约 5 V 工作点及慢漂会与静态响应混合，且传感器直流传递函数未知 |
| 本次水流产生的电信号 | 3.1 s 水力周期已由音视频确认，但 TDMS 没有跨条件复现的同步响应 |
| 任意未知弱信号的盲检 | 多频率、多通道搜索会产生大量偶然峰，3.49 uV 单目标门槛不再适用 |
| 仅凭频谱区分纯背景、STOP、30 Hz 和 50 Hz 全部状态 | 强 RUN 可以识别，但背景、STOP 和部分运行状态存在重叠 |
| 识别具体 VFD 设定载波 | 4/8/12 kHz 设置没有产生可重复的一一对应主峰迁移 |
| 判断高频究竟来自 VFD、电机、电缆还是泵负载 | 当前实验只分离了 STOP 与整条运行链 RUN，没有逐部件电气隔离 |

## 7. “检出信号”与“识别来源”必须分开

当前能力包含三个不同层次：

1. **检出：** 能否证明数据相对本地背景发生变化。
2. **识别：** 能否仅依据数据把记录分入背景、STOP 或强 RUN 等状态。
3. **归因：** 能否证明变化来自水流、电化学反应、VFD 功率器件或其他具体物理源。

现有系统已经能够检出并粗略识别强高频 RUN 状态；对水流低频电信号仍是未检出；对高频信号的归因目前只能到“VFD-电机-泵运行链”，不能进一步唯一定位。

## 8. 外部物理量检出限为什么仍然未知

可把测量系统写成：

\[
V_{\mathrm{out}}(f)=H(f,\theta)E(f)+n(f),
\]

其中：

- \(E(f)\) 是传感器位置处的外部电场；
- \(H(f,\theta)\) 是包含频率和方向的传递函数，单位可写为 V/(V/m)；
- \(n(f)\) 是传感器、采集和环境共同噪声。

只有测得 \(H(f,\theta)\) 后，输出端门槛才能换算为外场门槛：

\[
E_{\min}(f,\theta)=\frac{V_{\mathrm{out,min}}(f)}{|H(f,\theta)|}.
\]

若还要得到最小可检放电电流，需要再知道介质、电极和距离构成的传播函数 \(G\)：

\[
I_{\min}=\frac{V_{\mathrm{out,min}}}{|H(f,\theta)G(f,r,\sigma,\mathrm{geometry})|}.
\]

COMSOL 可以估计 \(G\)，但不能替代探测器本体的 \(H\)。现有 COMSOL 结果支持“水流源远弱于组合场和 VFD 源”的方向判断，但在完成传感器外场标定前，不能把仿真场强直接与 TDMS 的微伏门槛比较。

## 9. 对阴极保护和电化学放电监测的能力判断

### 9.1 最可能稳定检出的形式

- 外加电流按已知节奏周期通断；
- 正负极性可反转；
- 电流幅值分级变化；
- 同步记录电流参考；
- 探测器输出与参考序列具有稳定相关、正确极性和幅值缩放关系。

这种信号可以采用匹配滤波和多周期积累，检出条件明显优于未知频率的自然弱信号。若调制后在探测器输出端形成稳定的 5-10 uV peak 以上低频成分，且多数健康通道和重复 ABAB 序列一致，则按现有系统性能有较大希望稳定检出。

### 9.2 可能失败或被误归因的形式

- 持续不变的直流保护电流可能只在接通、断开时形成可见瞬态，稳态部分会与工作点和漂移混合。
- 弱随机电化学噪声没有已知时间参考，检出难度高于受控周期通断。
- 整流器、开关电源和长电缆可能产生比电化学场更强的 50/100 Hz 或高频信号。
- 只检测到与电源同时出现的谱线，不能证明探测到的是电极界面的电化学过程。

因此，对后续实验最准确的预测是：**受控、可同步、可反向、可分级的阴极保护电流具有较高检出希望；持续弱直流和自然随机微放电目前不能保证稳定检出。**

## 10. 建议采用的能力判定规则

### 10.1 低频已知周期或调制信号

同时满足以下条件才报告“检出”：

1. 目标频率由独立参考预先指定。
2. 单通道拟合峰值优先达到 5-10 uV peak。
3. 至少半数健康通道超过各自背景阈值，且空间幅值/极性模式可重复。
4. 至少三个 ABAB 周期中效应方向一致。
5. 第二台探测器或换位实验中，使用各自本机背景归一化后复现。
6. 关闭源或打乱参考序列时响应消失。

### 10.2 高频工况变化

同时满足以下条件才报告“稳定高频变化”：

1. 相对同一探测器、同一位置、相邻背景或 STOP 的频带增益达到约 2 dB 以上。
2. 多数健康通道同向变化。
3. 至少两个独立重复序列复现。
4. 若依赖窄谱线，谱线频率、增益和出现率均应复现，而不是只在单文件出现。
5. 跨日期比较必须重新测量背景，不能沿用固定绝对 dB 阈值。

上述规则是依据当前样本形成的工程规则。完成标准信号注入、更多背景重复和盲测后，才能把它升级为正式的检出概率、误报率和接收机工作特性指标。

## 11. 可用于论文或阶段汇报的能力表述

> 在 400 kHz 采样和约一分钟记录条件下，TC1/TC2 多通道监测系统能够稳定检出 VFD-电机-泵运行链产生的强高频窄谱线及频带能量变化。健康通道原始输出的宽带标准差约为 4 mV RMS；经 0.1 s 平均和固定频率相干拟合后，对 0.323 Hz 单一预设目标，背景表观周期峰值的经验 95% 分位为 3.49 uV peak。该结果表示当前系统对已知稳定周期输出变化的统计分辨能力，不等同于外部电场灵敏度。现有水流实验未检出可跨通道、跨探测器和跨摆位复现的 3.1 s 电响应，因此只能认定水流电信号低于当前系统在本场景下的可靠检出能力。由于探测器外场传递函数尚未标定，目前不能报告以 V/m、放电电流或探测距离表示的绝对检出限。

## 12. 当前能力等级

| 项目 | 等级 | 说明 |
|---|---|---|
| 强高频设备干扰监测 | 已验证 | RUN 相对 STOP 在两台探测器全部健康通道显著增强 |
| 高频状态粗分类 | 部分验证 | 强 RUN 可分；背景、STOP 和较弱状态仍有重叠 |
| 固定低频周期统计检测 | 分析能力已验证 | 已建立背景虚假幅值；尚缺标准物理信号注入 |
| 水流电信号检测 | 未检出 | 音视频有水力周期，TDMS 无复现电响应 |
| 稳态直流场检测 | 未验证 | 漂移和传递函数问题尚未解决 |
| 脉冲放电检测 | 未验证 | 采样率具备分析基础，但缺少标准脉冲注入和阈值实验 |
| 外场灵敏度 V/m | 未标定 | 缺少 \(H(f,\theta)\) |
| 最小放电电流与最大距离 | 未标定 | 同时缺少传递函数和传播函数 |

本报告描述的是截至 2026-08-08 的阶段能力边界。后续加入标准电场/电流注入后，应分别报告检出概率、假阳性率、幅频响应、相位响应、方向性、线性度和距离衰减，形成正式传感器性能规格。
