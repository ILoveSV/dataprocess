集中副本也保存在上级90_material_snapshot。新的映射工作要在舰艇侧源机制、参数证据及边界核验之后进行；需要连接的是接收点电场及其频谱/方向，不是把电源电流或实验几何直接乘一个比例。

上轮“1 A、10 m间距、5 m源深”的参考仍是有效数学算例，但不是本轮通用潜艇的公开来源参数。不得把其40.2 μV/m等结果改名为真实舰艇场强。
