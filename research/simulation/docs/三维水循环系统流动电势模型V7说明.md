# 三维水循环系统流动电势模型 V7 说明

## 1. 目的

V7 建立水循环系统的第一版流动电势源。它先计算管路内部压力和速度，再用薄双电层近似把压力梯度转换为流动电流，求得开路流动电势。该内部源将在后续 V8 中接入 5 m 空气域模型。

## 2. 默认普通参数

| 参数 | 默认值 |
|---|---:|
| 等效湿润回路长度 | 2.8 m |
| 水力直径 | 40 mm |
| 流量 | 6.3 m3/h |
| 水温 | 20 degC |
| 密度 | 998.2 kg/m3 |
| 动力黏度 | 1.002 mPa s |
| 电导率 | 0.05 S/m |
| 相对介电常数 | 80.2 |
| 壁面 zeta 电位 | -30 mV |
| 泵额定扬程参考 | 32 m |

其中水电导率和泵参数来自现有实验信息；温度、黏度、介电常数和 zeta 电位是普通水与常见聚合物界面的工程基线，不是实测值。

## 3. 方程

流动电流采用薄双电层近似：

```text
J_stream = -(epsilon*zeta/mu)*grad(p)
J_total = sigma*E + J_stream
div(J_total) = 0
```

流体使用 SST 湍流模型。DN40 管内平均速度约 1.39 m/s，雷诺数约 5.5e4，不适合使用层流假设。

## 4. 边界

- V7 是等效直管回路，包含总湿润长度，但尚未逐段绘制弯头、泵腔和水桶回流区。
- CFD计算得到的是管路摩擦压力损失。
- 32 m额定扬程只作为流动电势上限参考，不直接施加到短回路上。
- zeta 电位后续应扫描 -10、-30、-50 mV，并最终用实测值替代。
- 接触带电、气泡、空化、电化学反应和 `v x B` 感应将在后续模型中独立加入。

## 5. 基线求解结果

| 结果 | 数值 |
|---|---:|
| 管路雷诺数 | 55493 |
| 最大流速 | 1.411 m/s |
| 2.8 m等效直管压降 | 661.6 Pa |
| 流动电势绝对值 | 0.2812 mV |
| 最大管内电场 | 0.00880 V/m |
| 32 m额定扬程理论参考 | 0.133 V |

按相同压降直接代入 Helmholtz-Smoluchowski 关系得到 `0.2813 mV`，与COMSOL结果相差约 `0.037%`，宏观耦合实现通过量级校验。

当前 `0.2812 mV` 只包含等效直管摩擦压降。实际弯头、泵腔、法兰、局部收缩和回水入口会增加局部压力损失；另一方面，闭式回路各段流动电势方向及不同材料的 zeta 电位可能相互抵消。`0.133 V` 是把32 m额定扬程全部作为单一界面压降的上限参考，不代表真实短回路电压。

由于流动电势在当前模型中与 zeta 电位线性相关，`-10 mV` 和 `-50 mV` 对应的等效直管结果约为 `0.0937 mV` 和 `0.4687 mV`。
