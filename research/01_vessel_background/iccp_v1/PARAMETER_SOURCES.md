# ICCP 初版参数与来源

日期：2026-10-18。

此目录是新建的三维潜艇 ICCP 条件算例。它采用已发表的电化学边界与 COMSOL 方法，但不将几篇论文的参数拼接后声称为某一篇的原样复现。

| 项目 | 初版取值 | 来源及性质 |
|---|---|---|
| 三维潜艇 ICCP 方法 | 海水电流场、材料极化边界、独立外加电流阳极 | Schaefer 等，COMSOL Conference 2011，正文第2节 |
| 艇长、艇体中心浸深 | 50 m、20 m | Schaefer 等2019潜艇算例的尺度；并非2011论文完整CAD |
| 艇宽、附体与圆盘桨尺寸 | 宽6 m，其他见参数和源码 | 通用几何假设；指挥台与舵简化为块体 |
| 钢/桨材料 | HY-80、NAB | 2011、2018、2020论文均有此材料组合 |
| 极化曲线 | HY-80、NAB的净电流-电位插值 | Thiel 等2020图3b、3d的矢量路径数字化，不是作者原始测量文件 |
| 极化曲线电位参考 | Ag/AgCl | 沿用Thiel2020明确统一后的参考；未混用Kim2018的SCE电位 |
| 涂层 | 钢表面2%均匀有效破损，桨裸露 | 2%参考Kim2018算例，乘极化电流的均匀化实现参考Thiel2020 |
| 海水电导率 | 4 S/m | 参考韩国Chung2008的海水算例，作为常见条件值 |
| 阳极 | 四个，前后各一对 | 通用设置，不宣称为某型号真实阳极布局 |
| 阳极位置 | x=±12 m，y=±3.15 m，z=-20 m | 本轮假设；横向绝对位置随修改艇宽时也应检查 |
| 阳极半径、突出厚度 | 0.25 m、0.08 m | 本轮几何假设 |
| 绝缘屏蔽半径 | 0.75 m | 参考Thiel2020的1.5m直径绝缘区；为适配曲面，初版以绝缘圆柱座实现 |
| 总电流 | 0、5、10、20 A | 情景扫描；10A参照2011论文所示算例的工作量级，不代表当前几何已充分保护 |
| 电流分配 | 前后各50%，各舷均分 | 本轮假设；通过bow_share修改 |
| 金属内部连接 | 钢艇体和桨理想电连接，共同金属电位 | 初版假设，忽略金属压降、轴承接触电阻与回流磁场 |
| 水面 | 不导电的平整水面 | 海水稳态电流绝缘边界；本轮未另求空气静电场 |
| 远边界 | 有限水域远面电位0，水面除外 | 数值截断条件；基准半宽/深250m，扩大至375m核查，不是海底深度模型 |
| 保护参考值 | -0.8 V vs Ag/AgCl | 仅为展示保护覆盖率的示意判据，不代表完整标准或工程验收 |

## 曲线数字化的明确处理

从本地 `research/literature/raw/thiel2020.pdf` 第5页提取蓝色曲线的矢量顶点，横轴由对数A/cm2换算成A/m2。以曲线的最低电流转折处作为腐蚀电位，电位高于该处记为净阳极电流，低于该处记为净阴极电流。接近转折的±2mV范围以零电流点连接，按2mV分箱整理。

该图HY-80子图中“anodic/cathodic branch”文字标注与通常的净阳极电流正号约定相反，本模型按电位相对腐蚀电位恢复符号，没有照抄图中文字来翻转电化学反应方向。NAB的轻微图线回折通过非递减整理去除；最大修正及原PDF哈希均写入data/polarization_provenance.json。

COMSOL使用电位为自变量的分段线性插值；范围外采用端点线性外推，每个解均记录使用外推的表面面积比例。后续有原始曲线数据时，可直接替换插值表并重算。

## 后续修改时的关系

修改L、B、浸深或阳极位置后，需要重新生成几何和网格。修改材料曲线、涂层或供电电流后，需要重新求解非线性回路；不能只把旧场强乘电流比例。修改bow_share后，应继续核对两舷是否对称以及每只阳极的支路电流。
