# 舰艇电场纯理论计算任务说明 v0.1

更新时间：2026-07-02  
用途：供本地 Codex / 自动化代码助手执行理论计算、生成 LaTeX 推导、参数扫描表格和图。  
项目：水下目标探测与电磁仿真 / 水下舰艇电场源项与 MEMS 极化带效应接收理论估算。  

---

## 0. 总目标

本任务只做纯理论计算与解析量级估算，不做 COMSOL，不做有限元，不做三维真实舰艇几何建模，不做实验数据拟合。

总目标是建立一条可复现的理论计算链：

```latex
\text{舰艇等效电场源项}
\rightarrow
\text{导电海水传播衰减}
\rightarrow
\text{移动目标时间包络}
\rightarrow
\text{多通道接收电压/电场响应}
\rightarrow
\text{噪声谱与 SNR 判据}
\rightarrow
\text{最大可探测距离和优势源项排序}
```

最终产物不是“某型潜艇的精确电场”，而是：

1. 一份 LaTeX 理论推导文档；
2. 一套参数化 Python 计算脚本；
3. 若干 CSV 参数扫描表；
4. 若干 PNG/PDF 图，用于论文或 PPT；
5. 一份结论摘要，说明不同源项在不同距离、频率、噪声条件下的相对可探测性。

## 1. 必须冻结的研究边界

### 1.1 允许做的内容

只允许做以下内容：

1. 解析公式推导；
2. 量级估算；
3. 参数扫描；
4. 维度检查；
5. 极限情况检查；
6. 生成表格和图；
7. 写成可放入论文/PPT的 LaTeX 公式与说明。

### 1.2 禁止做的内容

严禁做以下内容：

1. 不做 COMSOL；
2. 不做 FEM/BEM/FDTD；
3. 不建立真实潜艇 CAD 几何；
4. 不声称计算结果代表某型真实潜艇；
5. 不把水泵 50 Hz 工频泄漏等价成真实潜艇主电场；
6. 不用 220 V / 380 V 电源直接作为真实舰艇源项；
7. 不凭空给出真实潜艇 ICCP 电流、涂层面积、轴系参数等保密或不可公开参数；
8. 不对 MEMS 芯片灵敏度作确定性承诺，除非输入中提供标定参数；
9. 不用复杂模型掩盖简单假设，所有假设必须显式写出。

### 1.3 核心物理对象

本任务只考虑水下低频/准静态电场。舰艇源项按以下优先级处理：

```latex
S_{\mathrm{ship}}
=
S_{\mathrm{UEP}}
+
S_{\mathrm{ICCP}}
+
S_{\mathrm{shaft}}
+
S_{\mathrm{wake}}
+
S_{\mathrm{noise}}
```

其中：

- `UEP`：腐蚀相关静态电场 / underwater electric potential；
- `ICCP`：外加电流阴极保护或牺牲阳极系统形成的电流场；
- `shaft`：轴频电场，即腐蚀/防腐蚀电流被轴系和螺旋桨周期调制形成的低频线谱；
- `wake`：尾流/流动诱导电场，作为辅线；
- `noise`：海洋环境噪声、平台噪声、工频干扰、电路噪声和漂移。

## Step 0：坐标系、几何关系与运动模型

### Step 0.1 定义

建立统一坐标系和目标运动几何。此步只处理几何，不计算电场。

### Step 0.2 输入

```latex
\mathbf r = (x,y,z)
```

```latex
\mathbf r_s(t) = \mathbf r_{s0}+\mathbf v t
```

```latex
\mathbf r_i = (x_i,y_i,z_i)
```

其中：

- `r_s(t)`：舰艇等效源中心位置；
- `r_i`：第 `i` 个接收点位置；
- `v`：目标速度向量；
- `R_i(t)`：源中心到第 `i` 个接收点的距离。

### Step 0.3 公式

```latex
\mathbf R_i(t)=\mathbf r_i-\mathbf r_s(t)
```

```latex
R_i(t)=|\mathbf R_i(t)|
```

若目标沿 `x` 方向匀速直线通过，最近距离为 `R_0`，则：

```latex
R(t)=\sqrt{R_0^2+v^2t^2}
```

最近时刻：

```latex
t=0
```

### Step 0.4 输出

1. `geometry.py`；
2. 表格：不同 `R_0`、`v` 下 `R(t)`；
3. 图：`R(t)` 曲线。

### Step 0.5 边界

不考虑加速度、不考虑转向、不考虑姿态变化、不考虑海流导致的目标偏航。

### Step 0.6 验收标准

1. 当 `t=0` 时，`R(t)=R_0`；
2. 当 `|t|` 增大时，`R(t)` 单调增大；
3. `R(t)` 关于 `t=0` 对称。

## Step 1：导电海水准静态控制方程

### Step 1.1 定义

建立低频/准静态舰艇电场的基本物理方程。

### Step 1.2 输入

```latex
\sigma
```

```latex
\rho_I(\mathbf r)
```

### Step 1.3 公式

```latex
\nabla\cdot(\sigma\nabla\varphi)=-\rho_I
```

```latex
\mathbf E=-\nabla\varphi
```

```latex
\mathbf J=\sigma\mathbf E
```

若海水均匀且各向同性：

```latex
\sigma = \mathrm{const.}
```

则：

```latex
\sigma\nabla^2\varphi=-\rho_I
```

```latex
\nabla^2\varphi=-\frac{\rho_I}{\sigma}
```

### Step 1.4 输出

1. 文档中的控制方程小节；
2. `constants.py` 中定义 `mu0`、默认 `sigma`；
3. 后续所有模型必须基于此方程。

### Step 1.5 边界

不处理完整 Maxwell 方程组；不处理高频辐射电磁波；不处理真实金属—海水界面的非线性极化曲线。

### Step 1.6 验收标准

文档中必须明确：本任务采用低频/准静态导电介质近似，适用于 UEP、ICCP 和轴频电场的初步估算。

## Step 2：舰艇源项等效模型定义

### Step 2.1 定义

把复杂舰艇电化学源项简化为多点电流源、电流偶极子和单等效偶极子三层模型。

### Step 2.2 输入

```latex
N
```

```latex
I_k
```

```latex
\mathbf r_k
```

### Step 2.3 公式

多点电流源：

```latex
\rho_I(\mathbf r)=\sum_{k=1}^{N}I_k\delta(\mathbf r-\mathbf r_k)
```

电流守恒约束：

```latex
\sum_{k=1}^{N}I_k=0
```

电流偶极矩：

```latex
\mathbf P=\sum_{k=1}^{N}I_k\mathbf r_k
```

单等效偶极子：

```latex
\mathbf P_{\mathrm{eq}}=I_{\mathrm{eff}}\mathbf L_{\mathrm{eff}}
```

### Step 2.4 输出

1. `source_models.py`；
2. 函数 `dipole_moment(currents, positions)`；
3. 文档说明真实舰艇源项如何等效为 `P_eq`。

### Step 2.5 边界

不计算真实船体上每一点的腐蚀电流；不拟合真实舰艇源分布；不考虑舰体细节、涂层破损、阳极具体位置。

### Step 2.6 验收标准

1. 对正负点源 `+I` 和 `-I`，间距为 `L` 时，输出 `P=I L`；
2. 若所有电流总和不为零，代码应发出警告；
3. 文档必须写明 `P_eq` 是参数化等效量。

## Step 3：UEP / ICCP 静态电流偶极子场计算

### Step 3.1 定义

计算等效电流偶极子在均匀无限海水中的电势和电场量级。

### Step 3.2 输入

```latex
P
```

```latex
\sigma
```

```latex
R
```

```latex
C_\theta
```

### Step 3.3 公式

点电流源电势：

```latex
\varphi(\mathbf r)=\frac{I}{4\pi\sigma|\mathbf r-\mathbf r_0|}
```

电流偶极子远场电势：

```latex
\varphi(\mathbf r)\approx
\frac{\mathbf P\cdot\hat{\mathbf R}}{4\pi\sigma R^2}
```

电场：

```latex
\mathbf E(\mathbf r)=-\nabla\varphi(\mathbf r)
```

量级估算：

```latex
E_{\mathrm{UEP}}(R)=\frac{C_\theta P}{4\pi\sigma R^3}
```

### Step 3.4 输出

1. `propagation.py` 中函数 `static_dipole_field(P, sigma, R, Ctheta=1)`；
2. CSV：`static_dipole_scan.csv`；
3. 图：`E_vs_R_for_P.png`，横轴 `R`，纵轴 `E`，建议双对数坐标；
4. 表格：不同 `P`、`R` 下的 `E`，单位包含 `V/m` 和 `uV/m`。

### Step 3.5 边界

只适用于远场近似：

```latex
R \gg L_{\mathrm{eff}}
```

不考虑水面/海底边界；不考虑频率衰减；不考虑目标运动。

### Step 3.6 验收标准

1. 固定 `P` 和 `sigma` 时，`E \propto R^{-3}`；
2. 固定 `R` 和 `sigma` 时，`E \propto P`；
3. 固定 `P` 和 `R` 时，`E \propto 1/\sigma`；
4. `test_scaling_laws.py` 必须验证上述三条比例关系。

## Step 4：海水电导率敏感性计算

### Step 4.1 定义

评估海水电导率不确定性对电场估算结果的影响。

### Step 4.2 输入

```latex
\sigma_{\min}=3\ \mathrm{S/m}
```

```latex
\sigma_{\max}=6\ \mathrm{S/m}
```

```latex
P, R, C_\theta
```

### Step 4.3 公式

```latex
E(R,\sigma)=\frac{C_\theta P}{4\pi\sigma R^3}
```

相对敏感性：

```latex
\frac{\partial \ln E}{\partial \ln \sigma}=-1
```

区间：

```latex
E_{\min}=\frac{C_\theta P}{4\pi\sigma_{\max}R^3}
```

```latex
E_{\max}=\frac{C_\theta P}{4\pi\sigma_{\min}R^3}
```

### Step 4.4 输出

1. CSV：`conductivity_sensitivity.csv`；
2. 图：不同 `sigma` 下的 `E(R)` 阴影区间；
3. 文档中说明 `sigma` 只造成线性比例变化，不改变 `R^{-3}` 距离衰减律。

### Step 4.5 边界

不使用复杂盐度—温度—压力经验公式；不处理空间非均匀电导率。

### Step 4.6 验收标准

当 `sigma` 从 `3 S/m` 增加到 `6 S/m` 时，`E` 应减半。

## Step 5：低频皮肤深度与频率衰减估算

### Step 5.1 定义

估算导电海水对不同频率电磁扰动的附加衰减，说明低频轴频电场比高频信号更适合水下传播。

### Step 5.2 输入

```latex
f
```

```latex
\mu
```

```latex
\sigma
```

```latex
R
```

### Step 5.3 公式

角频率：

```latex
\omega=2\pi f
```

皮肤深度：

```latex
\delta(f)=\sqrt{\frac{2}{\omega\mu\sigma}}
=
\sqrt{\frac{1}{\pi f\mu\sigma}}
```

频率衰减因子：

```latex
A_f(R,f)=\exp\left(-\frac{R}{\delta(f)}\right)
```

频率修正场：

```latex
E(R,f)=E_0(R)A_f(R,f)
```

### Step 5.4 输出

1. `propagation.py` 中函数 `skin_depth(f, sigma, mu=mu0)`；
2. `propagation.py` 中函数 `frequency_attenuation(R, f, sigma, mu=mu0)`；
3. CSV：`skin_depth_scan.csv`；
4. 图：`skin_depth_vs_frequency.png`；
5. 图：`attenuation_vs_distance_by_frequency.png`。

### Step 5.5 边界

`A_f` 是工程化附加衰减因子，用于量级比较；不替代准静态偶极子场的 `R^{-3}` 几何衰减。

### Step 5.6 验收标准

1. `delta(f) \propto f^{-1/2}`；
2. 频率越高，`delta` 越小；
3. 频率越高，同一距离下 `A_f` 越小。

## Step 6：轴频电场调制模型计算

### Step 6.1 定义

把轴频电场定义为 UEP/ICCP 等效偶极矩的周期调制分量。

### Step 6.2 输入

```latex
P_0
```

```latex
m_n
```

```latex
f_s
```

```latex
n
```

```latex
\phi_n
```

```latex
R, \sigma
```

### Step 6.3 公式

等效偶极矩时间变化：

```latex
\mathbf P(t)=\mathbf P_0+\Delta\mathbf P(t)
```

轴频调制分量：

```latex
\Delta\mathbf P(t)=
\sum_{n=1}^{N_h}
m_n\mathbf P_0
\cos(2\pi n f_s t+\phi_n)
```

第 `n` 阶轴频电场幅值：

```latex
E_{\mathrm{shaft},n}(R)=
m_n
\frac{C_\theta P_0}{4\pi\sigma R^3}
A_f(R,nf_s)
```

时间信号：

```latex
E_{\mathrm{shaft}}(t)=
\sum_{n=1}^{N_h}
E_{\mathrm{shaft},n}(R)
\cos(2\pi n f_s t+\phi_n)
```

### Step 6.4 输出

1. `source_models.py` 中函数 `shaft_rate_components(P0, m_list, fs, harmonics)`；
2. `propagation.py` 中函数 `shaft_rate_field(P0, m, fs, n, R, sigma)`；
3. CSV：`shaft_rate_scan.csv`；
4. 图：不同 `R` 下轴频分量幅值；
5. 图：模拟轴频线谱。

### Step 6.5 边界

不模拟真实螺旋桨、轴承、接触电阻；不声称 `m_n` 来自真实舰艇测量；`m_n` 仅作为参数扫描。

### Step 6.6 验收标准

1. 当 `m_n=0` 时，轴频分量为 0；
2. 当 `R` 增加 10 倍，忽略 `A_f` 时，轴频幅值约下降 1000 倍；
3. 当 `f_s` 增加时，`A_f` 下降。

## Step 7：移动目标时间包络计算

### Step 7.1 定义

将单点电场扩展为多接收点电势差或等效局部梯度。

### Step 8.2 输入

```latex
\mathbf r_i
```

```latex
\mathbf r_j
```

```latex
\varphi(\mathbf r,t)
```

```latex
\mathbf E(\mathbf r,t)
```

### Step 8.3 公式

第 `i` 个通道电势：

```latex
\varphi_i(t)=\varphi(\mathbf r_i,t)
```

电压差：

```latex
\Delta V_{ij}(t)=\varphi_i(t)-\varphi_j(t)
```

小间距近似：

```latex
\Delta V_{ij}(t)
\approx
-\mathbf E(\mathbf r_c,t)\cdot(\mathbf r_i-\mathbf r_j)
```

其中：

```latex
\mathbf r_c=\frac{\mathbf r_i+\mathbf r_j}{2}
```

等效梯度：

```latex
G_{ij}(t)=\frac{\Delta V_{ij}(t)}{|\mathbf r_i-\mathbf r_j|}
```

### Step 8.4 输出

1. `receiver_model.py` 中函数 `voltage_difference(phi_i, phi_j)`；
2. `receiver_model.py` 中函数 `small_baseline_voltage(E_vec, baseline_vec)`；
3. CSV：多通道 `Delta V_ij(t)`；
4. 图：不同通道的时间延迟/幅值差异。

### Step 8.5 边界

此步只对传统电势差阵列严格成立。对 MEMS 极化带效应芯片，只作为外场到通道输入的前级参考，不直接等价为芯片输出电压。

### Step 8.6 验收标准

1. 当两个接收点重合时，`Delta V=0`；
2. 当基线方向与电场方向垂直时，小间距近似 `Delta V≈0`；
3. 当基线长度翻倍时，`Delta V` 近似翻倍。

## Step 9：MEMS 极化带效应接收响应模型

### Step 9.1 定义

建立局部电场到 MEMS 多通道输出电压的参数化响应模型。

### Step 9.2 输入

```latex
E_i(t)
```

```latex
K_i(f,\theta,\sigma,T)
```

```latex
b_i(t)
```

```latex
n_i(t)
```

### Step 9.3 公式

单通道：

```latex
V_i(t)=K_i(f,\theta,\sigma,T)E_i(t)+b_i(t)+n_i(t)
```

多通道矩阵：

```latex
\mathbf V(t)=
\mathbf K(f,\theta,\sigma,T)\mathbf E(t)
+
\mathbf b(t)
+
\mathbf n(t)
```

若无芯片标定参数，则只输出电场层面的可探测性：

```latex
E_{\mathrm{local}}(t)
```

若给定 `K_i`，则输出电压层面的可探测性：

```latex
V_i(t)
```

### Step 9.4 输出

1. `receiver_model.py` 中函数 `mems_voltage(E, K, bias=0, noise=0)`；
2. 参数表：`K_i` 默认留空或设为符号参数；
3. 文档中明确：没有标定时不得声称实际芯片输出电压绝对值。

### Step 9.5 边界

不推导芯片内部极化带效应微观物理；不把 MEMS 通道间距简单等效为传统 Ag/AgCl 电极基线；不凭空给出灵敏度。

### Step 9.6 验收标准

1. 当 `K_i=0` 时，输出只剩 `b_i+n_i`；
2. 当 `E` 翻倍时，线性响应模型下 `V-b-n` 翻倍；
3. 文档必须区分 `外部电场 E` 和 `芯片输出电压 V`。

## Step 10：背景噪声谱模型

### Step 10.1 定义

建立可参数化的背景噪声模型，用于后续 SNR 估算。

### Step 10.2 输入

```latex
N_0
```

```latex
f_0
```

```latex
\alpha
```

```latex
A_k
```

```latex
f_{\mathrm{power}}
```

### Step 10.3 公式

总噪声谱：

```latex
N_{\mathrm{tot}}(f)=
N_{\mathrm{ocean}}(f)
+
N_{\mathrm{platform}}(f)
+
N_{\mathrm{circuit}}(f)
+
N_{\mathrm{power}}(f)
+
N_{\mathrm{drift}}(f)
```

参数化连续噪声：

```latex
N_{\mathrm{cont}}(f)=N_0\left(\frac{f}{f_0}\right)^{-\alpha}
```

工频线谱干扰：

```latex
N_{\mathrm{line}}(f)=\sum_{k}A_k\delta(f-kf_{\mathrm{power}})
```

实际计算中不能使用真正的 Dirac delta，应使用窄带峰近似。

### Step 10.4 输出

1. `noise_model.py` 中函数 `continuous_noise(f, N0, f0, alpha)`；
2. `noise_model.py` 中函数 `line_noise(f, peaks, bandwidth)`；
3. CSV：`noise_spectrum_examples.csv`；
4. 图：低频噪声谱示意。

### Step 10.5 边界

如果没有实测噪声底，本步只做参数化扫描，不给出确定探测结论。

### Step 10.6 验收标准

1. `alpha>0` 时，低频噪声高于高频噪声；
2. 工频峰只在指定频率附近抬高噪声；
3. 文档必须区分自然噪声、平台噪声、工频干扰和电路噪声。

## Step 11：SNR 与最大可探测距离计算

### Step 11.1 定义

将源项电场、传播衰减、接收响应和噪声谱合并，计算 SNR 与理论最大可探测距离。

### Step 11.2 输入

```latex
E_j(R,f)
```

```latex
N_{\mathrm{tot}}(f)
```

```latex
M
```

```latex
B
```

```latex
T
```

```latex
\gamma
```

### Step 11.3 公式

单频 SNR：

```latex
\mathrm{SNR}(R,f)=
20\log_{10}\left[\frac{E_j(R,f)}{N_{\mathrm{tot}}(f)}\right]
```

多通道理想相干增益：

```latex
G_M=10\log_{10}M
```

窄带积分处理增益：

```latex
G_T=10\log_{10}(BT)
```

有效 SNR：

```latex
\mathrm{SNR}_{\mathrm{eff}}
=
\mathrm{SNR}_0+G_M+G_T-L_{\mathrm{loss}}
```

检测条件：

```latex
\mathrm{SNR}_{\mathrm{eff}}(R,f)\ge \gamma
```

忽略频率指数衰减时的解析距离：

```latex
R_{\max}\approx
\left[
\frac{C_\theta P m_n G_{\mathrm{proc}}}
{4\pi\sigma E_{\min}}
\right]^{1/3}
```

若考虑频率衰减：

```latex
E(R,f)=
\frac{C_\theta P m_n}{4\pi\sigma R^3}
\exp\left(-\frac{R}{\delta(f)}\right)
```

此时 `R_max` 需要数值求根：

```latex
\frac{C_\theta P m_n}{4\pi\sigma R^3}
\exp\left(-\frac{R}{\delta(f)}\right)-E_{\min}=0
```

### Step 11.4 输出

1. `snr.py` 中函数 `snr_db(signal, noise)`；
2. `snr.py` 中函数 `processing_gain(M, B, T, loss)`；
3. `snr.py` 中函数 `solve_detection_range(...)`；
4. CSV：`snr_range_scan.csv`；
5. 图：`SNR_vs_R.png`；
6. 图：`Rmax_vs_P.png`；
7. 图：`Rmax_vs_noise_floor.png`。

### Step 11.5 边界

如果没有真实噪声底和 MEMS 灵敏度，`R_max` 只能是参数化理论曲线，不是实际系统探测距离。

### Step 11.6 验收标准

1. 噪声越低，`R_max` 越大；
2. `P` 越大，`R_max` 越大；
3. `m_n` 越大，轴频 `R_max` 越大；
4. 通道数 `M` 增大时，理想 SNR 增加 `10log10(M)`；
5. 若损失 `L_loss` 增大，`R_max` 应下降。
