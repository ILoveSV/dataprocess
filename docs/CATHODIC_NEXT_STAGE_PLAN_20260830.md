# 阴极保护下一阶段计划

## 1. 当前已经完成到哪里

旧约1 cm电极间距数据已经完成频域、CWT/SST、交叉小波、周期折叠、指数弛豫、projection-MEMD、400 kHz高频频带与相干、多通道配对状态、剂量及跨重复迁移分析。现有数据没有形成可跨重复识别的阳性特征。

继续在旧数据上增加分类器或事后挑选频带，信息增量很低，并会扩大假阳性。下一阶段应冻结判据，等待约30 cm正确几何的新数据。

## 2. 新数据最低要求

1. 明确记录电极间距、探测器、探测器位置和方向、电源设定电流及实际显示电压/电流。
2. 每个TDMS文件只对应一个协议，文件名包含几何、探测器、工况、电流和独立重复编号。
3. 每个文件前后保留至少30 s OFF；周期实验至少12个完整周期。
4. 至少进行两次独立重复。独立重复必须重新开始采集，不能把同一文件拆成两份。
5. 开路对照使用相同开关动作和时序，但电极回路保持断开。
6. 记录实际切换时刻。优先保存独立电流/电压时间序列；做不到时，保留带电源显示和统一计时画面的连续视频及手动时间表。
7. 保留原始400 kHz TDMS，分析过程中继续逐文件动态判断坏道。

## 3. 建议协议

### 3.1 快速周期识别

- 背景：全部关闭，连续60--120 s，重复2次。
- 开路对照：5 s ON / 5 s OFF，12周期，重复2次。
- 闭路强阳性：优先3 A，5 s ON / 5 s OFF，12周期，重复2次。
- 电流剂量：条件允许时增加0.1、0.5、1、2 A；每档12周期，至少2次独立重复。
- 电流档位顺序随机或正反各做一次，避免时间漂移伪装成剂量关系。

### 3.2 弛豫识别

- 选择3 A及一个中间电流。
- 30 s ON / 60 s OFF，至少6周期，重复2次。
- 该协议用于辨识充电、回落和时间常数；不能用5 s短周期替代。

## 4. 数据到位后的固定分析顺序

1. **完整性审计**：采样率、时长、削顶、掉点、逐文件健康通道、实际切换时刻。
2. **盲化元数据**：分析脚本使用匿名工况ID；完成特征和显著性表后再解盲。
3. **准静态周期**：固定目标频率、邻频置换、AR(1)红噪声CWT、SST和交叉小波循环移位。
4. **时域波形**：周期折叠、留一周期相关、ON/OFF边沿、单/双指数及时间常数可辨识性。
5. **多通道状态**：周期配对ON-OFF状态方向、精确符号翻转、开路对照比较。
6. **跨重复迁移**：第一次记录学习状态方向，只在第二次记录检验；随后反向检验。
7. **高频审计**：2--20、20--80、80--200 kHz逐周期带功率、跨通道相干和相位锁定。
8. **剂量与几何关系**：只在前述特征预先通过后检查电流单调性和与旧几何的差异。
9. **识别评估**：以整次独立实验为分组做留一识别和标签置换，不把通道、窗口或周期当独立样本。

## 5. 阳性验收门槛

候选必须同时满足：

1. 本地背景或OFF对照下方向明确，方法族FDR q<0.05。
2. 至少两次独立闭路重复同向，且跨重复迁移通过预定义检验。
3. 开路对照不出现同等效应。
4. 名义切换时刻前后1 s敏感性不改变结论；有同步电流轨迹时以实际时刻为准。
5. 对动态坏道和合理轻预处理稳定。
6. 物理方向与电流或电偶极矩变化不矛盾。

未同时满足时，只能标记为探索性候选，不能写成“稳定检出阴极保护信号”。

## 6. 数据到位后的产物

- 文件与协议清单、动态坏道表。
- 逐方法文件级特征和FDR表。
- 周期、弛豫和多通道状态图。
- 跨重复迁移矩阵及盲识别混淆矩阵。
- 阳性、定量阴性、探索性和数据不足四级结果矩阵。
- 与旧1 cm实验分开表述的最终检测能力结论。
