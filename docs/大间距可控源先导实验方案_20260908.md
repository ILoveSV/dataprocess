# 大间距可控水中源先导实验方案

编制日期：2026年9月8日。状态：待实施方案，不含新增实验结果。

本轮先回答两个问题：可控水中源通断是否伴随可重复的探测器输出变化；在同一批次中，增大电极间隙是否改变该响应。优先把源端实际输入、探测器输出和操作时刻对应起来，再决定是否扩大电流、距离或频率矩阵。

本方案沿用现有装置，将原约1 cm和计划约30 cm作为待实测的表面间隙名称。它们不是预先认定的错误或正确几何。有效中心距需独立记录；旧材料中约5倍的偶极矩估计不作为输出幅度必须增加5倍的验收条件。电流档位由现有设备、电极和现场条件确定，本方案不把3 A或其他固定档位称为必然可检出的强阳性。

## 1 实验前把测量链认清

确认TC1、TC2与TDMS通道的对应关系，记录实际启用的探测器、读出前端、采集模块、输入量程、采样率，以及前端是否隔直或具有高通响应。没有核实的项目填写“未核实”，不能根据通道名称补猜型号。先保存一段背景，检查掉点、削顶、失效通道和明显漂移。

如具备输入可测的标准激励，先做测量链检查。前端输入检查用于判断读出链能否响应；完整外场检查用于判断外部激励能否传到探测器。两者应分开记录，不用前端直接注入的阳性替代外场感测能力。标准激励形式、幅度、频率、参照仪器和接法均在操作前记录。

若尚无标准外场条件，仍可进行本次水中源先导，但结果解释须保留“测量链尚未独立标定”这一限制。首次未检出不能直接判定水中没有外场，也不能判断是哪一级链路失效。

## 2 第一轮工况

第一轮固定一种探测位置与方向，优先使用一个适用电流档位，暂不做完整剂量扫描。工况按下表区分，实际通电状态在记录中展开填写。

| 代号 | 条件 | 主要目的 |
| BG | 相邻背景 | 测量本批次前后背景及漂移；明确哪些设备仍通电 |
| OPEN | 相同时序开路操作 | 检查开关动作、驱动控制及线缆耦合产生的变化 |
| SMALL | 小间隙闭路 | 建立当天的小间隙参照，不依赖旧日期记录 |
| LARGE | 大间隙闭路 | 检查增大间隙后的候选响应 |

建议起始顺序为 BG → OPEN → SMALL → LARGE → LARGE → SMALL → OPEN → BG。每个箭头后的记录独立重新开始采集，两个同名工况也保存为不同文件并记录时间间隔。这是先导顺序，采用往返次序以便观察漂移；两次记录只提供初步重复性，不等于已完成跨日期确认。

大小间隙比较尽量保持实际电流、探测器位置与方向、水体条件、浸水面积和线缆走向一致。间隙改变可能使端电压、接触及线缆位置改变，必须如实记录。若某项无法保持，后续不得把全部输出差异只归因于间隙。

如果时间不足，优先保留背景、开路、大间隙闭路和独立重复；但缺少当天小间隙时，本轮只能回答大间隙条件下是否有候选，不能确认增大间隙的净效应。

## 3 通断时序如何确定

先导开始时先观察一次包含激励前、通电和关断后区间的完整变化，依据实际电流稳定时间、输出漂移和关断回落选择后续观测长度。每条周期记录均保留激励前及关断后的观察区间；不要只截取看起来最明显的几个周期。

5 s ON/5 s OFF或30 s ON/60 s OFF可作为历史设置参照，但本轮不将它们写为必须执行的固定值。若通电尚未稳定就已关断，延长ON；若关断后尚未回到可比较水平，延长OFF。改变时序后启用新的协议编号，不能将两种协议合并当作同一重复。

先导确定后，把电流档位、通断时长、周期数和主要观测指标登记为版本P1，再用于后续独立记录。分析允许观察平台差、周期响应或瞬态中的一种明确现象，不要求它们同时出现，也不要求所有响应均能用指数弛豫解释。

## 4 必须关联的源端与输出记录

优先同步记录实际I(t)、V(t)及切换标记，同时保留完整原始TDMS。记录两个采集系统是否共用时钟、触发或仅有软件时间；不能因为文件开始时间相近，就称为硬件同步。

若暂不能同步保存源端波形，使用能同时看到电源显示和统一计时的连续视频，并填写实际操作时刻。视频与手动时间表只是降级参照，必须估计时间不确定度。源端显示值不能替代高带宽纹波测量，视频也不能恢复其采样不到的快速变化。

记录表面间隙、有效中心距、两电极形状及浸水面积、水体电导率和温度、探测距离的起止点、探测器方向、线缆走向、接地状态及周围运行设备。每次换位拍摄能看清尺度和布线的照片，照片名写入对应记录。

## 6 数据回来后的固定分析

首先核对文件完整性、源端输入、时间对齐和逐文件通道健康状态。共同通道由同批参与比较的记录确定，不根据哪组更显著来选通道。原始绝对电压保留float64后去均值；完整PSD与高频窗口支路分开保存计算清单。

主指标依据先导观察登记为少量明确问题。例如有稳定平台时比较同周期ON与OFF差；有与实际输入对应的周期时检查周期平均及与参照的同步关系；只有瞬态时则以触发平均和重复波形为主。拟合指数模型仅在观察窗口足够、参数可辨识且相较简单模型确有改善时进行。

先报告单次记录内的效应幅度及波动，再检查独立记录间是否同方向、开路是否出现类似变化、大小间隙是否存在可重复差别。将通道、周期和短窗口当作同一记录内部的数据层次，不当作额外独立实验。计算统计显著性时说明检验集合；先导选择过的指标在新记录上确认。

如使用分类，应在一份记录确定特征和参数，在另一份独立记录检验，并保留本地背景。运行标签不能直接改写为水流标签。已有水泵相干结果不预设为水中源最优特征，也不把每一种探索方法都作为本轮验收必经项目。

## 7 根据结果选择下一步

| 先导观察 | 下一步优先检查 |
| 标准外场也没有明确响应 | 测量链频响、连接和背景；不直接扩大水中源矩阵 |
| 标准外场有响应而水中源没有 | 实际电流、源几何、水体条件和传播路径 |
| OPEN与闭路出现类似变化 | 开关、电源及线缆耦合；必要时补合适负载对照 |
| 只有闭路出现可重复变化 | 补跨时段或新日期验证；再用几何、负载或独立水中参照区分来源 |
| 大小间隙均有变化且差异重复 | 检查实际输入和电极状态，建立条件限定的几何关系 |
| 单次明显但另一重复消失或反向 | 优先解释漂移和装置变化；保留候选，暂不扩大结论 |

只有闭路阳性仍不足以唯一证明水中场耦合，因为闭路也改变电源负载和电缆电流。后续对照根据候选特征选择，第一轮不必一次铺开全部变量。

## 8 本轮完成后交付什么

现场交付原始TDMS、实际源端记录或连续视频、完整元数据表、切换时间表及几何照片。分析交付每条记录的质量表、少量主指标与原始对照图、独立重复比较及能够支持的结论。若未检出，明确实验条件和未解决的链路限制，不给出未经外场标定的绝对检出下限。

本方案参考现有研究进展复核和旧阴极保护实验结果，并针对旧计划过于固定的电流、时长及多方法门槛作了调整。下一步实际实验由现场执行，本文件只完成记录与分析准备。
