# DPS150与电极实验：精简交接

更新：2026-11-04。仅作为本轮电源及电极接线工作的接续记录，不替代PROJECT_STATE.md中的研究主线。

## 目标与范围

- 为不锈钢—水—石墨电化学装置提供带直流偏置的周期电流，探索轴频相关电流调制的等效激励。
- 用户明确取消本轮PPT制作。只做计算、设备测试和必要记录，PPT与整理由用户负责。
- 本轮采集的是电源串口遥测，没有采集TC传感器数据，没有新增目标检出结论。

## 设备及控制

- 电源：FNIRSI DPS-150，硬件V1.0，固件V1.2。
- USB：Micro-USB数据口，COM3，VID:PID=2E3C:5740；Type-C或DC另供电。正常输入回读约9 V。
- 串口协议：115200、8N1、RTS/CTS，社区原始实现为cho45/fnirsi-dps-150。
- SET命令0xB1，GET命令0xA1，会话命令0xC1。电压设定寄存器193，电流设定194，输出开关219，完整快照255。浮点小端32位。
- Python为D:/Anaconda/python.exe；串口依赖独立放在local/workbench/dps150_deps，不修改全局Python环境。
- 控制脚本在local/workbench：dps150_no_load_check.py、dps150_pipe_test.py、dps150_rate_benchmark.py。
- 用户已授权当前低电流通路及更新率测试。已实施最高电压上限1 V、电流设定10 mA，每轮结束关闭输出。新接法应先读状态，再从小电流检查，不自动扩大电压电流。

## 已完成测试

1. 空载：1 V/2 V/1 V设定及回读成功；结束输出关闭。初次仅接数据线时输入约3.79 V、欠压，主供电接入后恢复。
2. 小钢管直接连接正负输出：10 mA进入CC。随后完成2—10 mA、0.05 Hz、40点/周期、两周期调制；发送间隔约0.492—0.512 s，最大迟到约16 ms。只验证主机调度和内部回读。
3. 更新率：200次/秒通过8秒短测及15秒复测，后者3000个SET+GET设定寄存器逐点一致。往返中位约2.25 ms，发送迟到P95约0.341 ms，最大12.842 ms。
4. 240/320次每秒虽全部返回正确设定值，但未满足本轮时序标准。200次每秒是当前主机和程序已测通过档位，不是电源固有极限，更不是已测模拟电流带宽。
5. 新接真实实验不锈钢管：一端用防水结构伸出的引线，另一端夹裸露电极表面。第一次1 V/5 mA呈CV、1 V/0 mA，未测通。用户调整后，5 mA和10 mA均进入CC。5 mA电压回读约0.025—0.221 V，10 mA约0.226—0.161 V，接触稳定性仍待核实，不据此计算钢管电阻。
- 最近一次结束：输出OFF，电压设定0 V，回读电压/电流均0；电流限值保留10 mA。该状态为测试结束时确认，下一次操作仍先重新读取。

## 关键计算与解释

- 更新频率与调制频率不同：fu=N*f0。2次/秒、40点/周期对应0.05 Hz。
- 舰船轴频电场文献常用约1—7 Hz范围，具体潜艇取决于转速；慢变化预实验不能直接宣称复现典型轴频，频率缩放需另论证。
- 目标电流I=I0+A*sin(2πf0t)，I0>A时总电流始终同向，仍包含交流分量；不必采用零均值反向交流。
- 理想等间隔零阶保持：G=sin(π/N)/(π/N)，全频THD=sqrt(1/G²-1)，确定性滞后180/N度，跳变上界2A*sin(π/N)。上述量只适用于理想设定波形。
- N=40：基频衰减0.103%、全频THD4.54%；N=100：衰减0.016%、THD1.81%。首个额外谱线为(N-1)f0，不能把全频THD直接等同于目标低频带内失真。
- 按不超过200次/秒：1 Hz可用N200、理想THD0.91%；2 Hz N100、1.81%；5 Hz N40、4.54%；7 Hz用196次/秒、N28、6.49%。未包含量化、模拟响应、实际抖动与电极非线性。
- 官方电流设定分辨率1 mA；4 mA交流峰值只跨少数等级，合成量化失真显著，增加点数不能消除。50 mA等较大幅值只用于计算示例，本轮未施加。
- 接收场映射还要求实际基频电流、源空间分布、边界和传播响应有依据；同电源设置不自动等于同接收场。

## 当前问题及下一步

- 用户询问石墨能否直接接电。石墨可导电，可在干燥的两处接触点之间用限流小电流验证引线与石墨的通路。
- 单块石墨或钢管的两端直接连正负，是材料/接触通路测试。正式电化学回路应为电源—电极—水—另一电极—电源，两电极不能金属直连形成旁路，接线金属尽量保持水外或绝缘密封。
- 尚未测试石墨新接法，也未在真实水中电化学负载下验证调制波形。
- 必须用独立电流/端电压测量评估真实幅相、失真与重复性。内部遥测在小电流下与设定值高度一致，近零电压也有偏差，不能作为高精度独立计量。
- 是否换设备取决于带载波形与所需电流，不因单向直流输出本身而换。候选为带直流偏置的正弦恒流源、电化学工作站或硬件波形电源。
