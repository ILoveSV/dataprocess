日期：2026-09-20

## 一、导师提出的核心调整

### 1. 研究对象与分析方法需要形成明确对应

当前研究同时涉及传感器及采集链、水泵运行、水体脉动、VFD与电源干扰、电化学受控源、主动脉冲和仿真模型。分析方法也包含时域、频域、时频、多通道分解、相干、弛豫及分类。后续汇报和论文不能按方法名称平铺，而要回答：

1. 面向哪个研究对象；
2. 需要回答什么问题；
3. 使用哪种方法；
4. 得到了什么证据；
5. 结论能够写到什么程度。

算法数量不构成创新点。方法只有在解决明确问题并形成可重复证据时，才构成研究贡献。

### 2. COMSOL与理论计算需要承担实验到真实场景的桥梁作用

现有COMSOL工作主要描述实验装置和实验参数。导师要求进一步说明：实验条件下测得或计算的量，与真实海洋目标场景之间存在什么量级关系。

这一关系可以表现为：

- 有适用理论时，给出表达式并拟合或确定关键参数；
- 暂时无法建立统一表达式时，给出实验条件与真实条件的对照表；
- 对每种源分别说明源强、传播环境、距离和接收响应如何变化。

需要明确区分三个层次：

1. 源机制：水流、电化学、电缆或设备怎样形成等效源；
2. 场传播：等效源在水体和实际边界中形成多大电场；
3. 接收耦合：外部场怎样转换成传感器和采集系统的输出电压。

当前已经有部分源与传播结果，但外部场到传感器输出的独立标定尚未完成，因此不能直接由COMSOL场强推出仪器检出距离。

### 3. 电化学实验需要补连续低频激励

旧阴极保护实验以手动开关和ABAB通断为主。开关周期虽然很慢，但开关边沿包含较宽频率成分，瞬态响应与持续低频响应需要分别分析。

下一次实验优先采用能够输出连续、平滑低频变化的电源或电流驱动，形式可参考：

\[
I(t)=I_0+\Delta I\sin(2\pi f t)
\]

实验需要记录实际电流和电压波形，不能只使用电源设定值。频率与调制幅值应分别控制。

### 4. 新实验需要在一次连续采集中保留完整五阶段

每次实验应连续记录：

1. 激励前背景；
2. 启动或上升阶段；
3. 持续激励阶段；
4. 关闭或下降阶段；
5. 激励后背景。

前后背景需要单独比较。若前后背景发生变化，则工况差异中包含环境漂移，不能全部归因于受控源。背景校正需要以相邻背景和统计模型为依据，不能简单逐点相减。

### 5. 当前结果与创新点的定位

现有工作已经完成大部分实验与分析链，可以总结为：

- 已建立动态坏道、本机背景、完整记录和重复性检查流程；
- 已发现运行链相关的频谱、时变包络和跨通道相干变化；
- 已完成探测器换位、工况拆分和载波扫描等控制实验；
- 已给出旧阴极保护装置条件下未形成稳定阳性的检测边界；
- 已形成部分实验条件下的COMSOL源和传播结果。

尚缺的主要内容是：

- 实验条件到真实场景的量级映射；
- 连续低频受控源实验；
- 新数据上的独立识别验证；
- 场强到传感器输出的标定关系。

“能够区分部分状态”和“得到条件性检测边界”可以作为研究结果，但暂时不能单独作为完整创新点。候选创新方向包括物理约束的量级映射，以及结合相邻背景、阶段响应和跨通道关系的辨识方法。

## 二、当前优先任务

1. 整理“研究对象、问题、方法、证据和结论边界”总表。
2. 整理“实验条件与真实条件”对照关系，明确已完成量、待计算量和待标定量。
3. 后续补充真实场景COMSOL代表算例和量级表。
4. 设计连续低频受控源及五阶段采集实验。
5. 新数据到位后，完成重复性和独立识别验证，再确定论文创新点表述。

## 四、2026-09-25更新：创新点顺序与理论主线

按用户最新要求，创新点顺序固定为：

1. 物理场量级关系与实验映射（原创新点2）；
2. 面向弱电水下目标实验的信号归因方法（原创新点1）。

本阶段先从水下目标电场/电流密度源机制出发，梳理电化学直流及其调制、水体运动感应、管壁界面电动与设备杂散场。ICCP不等于纯直流；螺旋桨几何调制较弱不能推广为所有轴频回路调制可忽略。旧理论稿的3%调制比例是参考假设，不是实测结论。

现有水流V10主要为管路界面流动电势模型，不等同于海洋尾流的运动感应模型。当前桶外空气接收与真实场景之间优先采用分别建模的传播映射，不能只按尺寸直接放大。

理论初稿及可复算量级表已新增：[创新点1：源机制与缩比映射](创新点1_源机制与缩比映射_理论初稿_20260925.md)。计算复核了已有外场模型的间隙与共模敏感性，但没有新增COMSOL求解、实物实验或传感器标定。

表述边界：允许写“建立分层量级分析框架，为未检出提供条件性解释”；尚不允许写“唯一证明未检出原因”“已得到真实海洋探测距离”。下一步仍需明确接收介质与通道物理量，补真实源/边界参数和外场到输出的黑箱标定。

另已核对9月21日连续启停及9月22日逐路融合报告：新数据支持运行状态相关变化的探索性识别，不把其分类成绩直接作为水流电场已检出的证明。本轮没有重新训练或改变候选识别器。

## 五、2026-09-28更新：优先审查整条研究连接

用户最新要求：继续补全真实舰艇背景到实验的完整链条，主要精力用于方向、假设和逻辑缺口的审查，其后才是计算建模。当前专项依据见[研究链条审查](../research_materials/00_chain_review/研究链条审查与推进依据_20260928.md)，不按旧PPT交付或论文写作任务自动推进。

主线固定为：真实源及时间变化 → 接收场 → 实验输入和边界 → TC幅相/方向响应 → 归因与独立检测。水泵/VFD实验用于干扰和状态响应，电极实验用于水中闭合电流源；二者不分别冒充整艇缩比和已校准电场源。源强可用完整电化学情景或具有完整元数据的外场基准约束，不要求无限细化缺参数的艇体模型。

本轮对旧桶外线性模型进行复矢量分解：0.001 Hz、指定接地和布线下，每伏共模场模响应约为每伏差模的14–24倍。该结果强调共模缺口，不证明实测主要由共模造成。10至300 mm固定电流缩放仍为约4.24–4.36倍；“小间距是未检出的主要原因”保留为待验证解释，不当成已经证明。场模、方向分量和TC输出必须分开，未标定前不报海上检测距离。

新增8项测试与旧16项解析测试均通过；未新增实物实验、未运行新COMSOL求解、未重跑原始数据。下一步优先补有出处的背景源约束与接收/供电条件，具体模型只为消除这些关键不确定性服务。

同日续查增加“源端口一致性”检查，详见[源强依据与实验输入核验](../research_materials/01_vessel_background/source_constraints/源强依据与实验输入核验_20260928.md)。旧模型按报告电流与电压归一化的场预测明显不相容，尚不能用于实际绝对场标定。12通道已在旧诊断中确认为不同位置的芯片，本轮只把位置映射、量程和响应继续列为待补。公开潜艇论文的无刻度场图不能定标；有绝对数值但边界不完整的算例仅作量级参考。没有据此修改实验阳性/阴性或升级探测距离结论。
