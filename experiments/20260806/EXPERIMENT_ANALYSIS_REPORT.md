# 2026-08-06 交叉校准与 VFD 载波实验分析报告

> **口径更新：仅上电、不开泵，不能稳定与纯背景区分。** 见[换位对照全段结果](duo_crossover_summary.csv)。第五节及第七节中的“所有有效通道高频显著增强”属于早期近似结果，已由 [RUN 对 STOP 全段重算](vfd_band_contrasts.csv)替代。不要引用旧增幅作为当前结果。

## 1. 数据与处理范围

- 数据根目录：`D:\Lab\raw\26.8.6`。
- 共分析 32 个 TDMS 文件：TC1、TC2 各 16 个；每个文件 12 通道，采样率 400 kHz，时长约 81–90 s。
- `duo`、`duo2` 为两台探测器同时测量并交换位置的两组实验；同步分析采用共同有效时段约 54.6–62.2 s。
- VFD 组包括背景、VFD 上电 STOP，以及载波 4/8/12 kHz × 输出 30/50 Hz 的完整组合。
- 共分析 10 个视频的音轨和画面运动。视频未与 TDMS 做强制逐秒对齐，只按文件名作为相应工况的独立状态参考。

处理时先在全部 32 个文件上做通道健康筛查，然后固定排除坏道。频域统计采用 `5–100 Hz`、`100 Hz–1 kHz`、`1–20 kHz`、`20–80 kHz`、`80–200 kHz` 五个频带；水流周期检验使用视频音轨独立给出的约 3.10 s（0.323 Hz）作为预先指定目标，而不是从 TDMS 中反向挑峰。

## 2. 通道健康结论

确定三个持续异常通道：

| 探测器 | 坏道 | 异常性质 | 持续性 |
|---|---:|---|---:|
| TC1 | 12 | 1–20 kHz 噪声比正常通道约高 20 dB | 16/16 文件 |
| TC2 | 8 | 直流约 0.5–0.7 V，正常通道约 5 V；低频漂移约高 70 dB | 16/16 文件 |
| TC2 | 11 | 1–20 kHz 噪声比正常通道约高 17 dB | 16/16 文件 |

后续结论均排除 TC1-12、TC2-8、TC2-11。自动筛查得到的 48 个异常“文件×通道”记录正好全部来自这三个通道，没有发现额外的偶发坏道。

## 3. 交叉校准结果

### 3.1 两台探测器不能直接混合绝对幅值

换位模型得到的背景表观 TC1−TC2 差异为：`5–100 Hz 0.13 dB`、`100 Hz–1 kHz 0.46 dB`、`1–20 kHz 4.51 dB`、`20–80 kHz 2.07 dB`、`80–200 kHz 2.82 dB`。因此低频底噪较接近，但 TC1 在高频绝对幅值上通常比 TC2 高约 2–4.5 dB。

这只能视为本次实验中的频带校正参考，不能作为永久标定系数。两次换位并非同一时刻完成，50 Hz 工况第二组在两台探测器上同时出现 `20–80 kHz` 约 9–12 dB 的额外增强，说明源状态或环境随时间的变化可大于位置效应。

### 3.2 低频没有形成可复现的工况差异

30 Hz 工况相对各自摆位背景：

- `5–100 Hz` 仅增加 0.08–0.71 dB；
- `100 Hz–1 kHz` 为 −0.19–0.67 dB；
- 换位后没有保持稳定的探测器差值或位置差值。

两台仪器同步包络的零延迟绝对相关系数中位数，在 30 Hz 工况四类特征中仅约 0.10–0.14；允许 ±1 s 小范围时移后也仅约 0.17–0.24。超过 `|r|=0.3` 的通道比例通常为 6%–22%，与背景量级相近。

因此，当前数据不支持把 TC1、TC2 的低频瞬态直接当作同一物理波形，也不支持合并两台仪器的原始幅值。可靠做法是固定坏道掩码，并在每台探测器内部相对本机、本摆位背景计算变化量。

## 4. 水流周期检验

### 4.1 视频/音频确认了水力循环

排除重复文件后，30 Hz 视频音轨在不同载波设置下给出：

| 文件 | 载波设置 | 音频周期 | 强周期窗口占比 |
|---|---:|---:|---:|
| `4k30hz.mp4` | 4 kHz | 3.14 s | 100% |
| `4k30hz2.mp4` | 4 kHz | 3.12 s | 100% |
| `8k30hz.mp4` | 8 kHz | 3.07 s | 100% |
| `12k30hz2.mp4` | 12 kHz | 3.04 s | 100% |

这说明约 3.1 s 的周期属于 30 Hz 运行时稳定存在的水力/声学循环，并且基本不随 VFD 载波设置改变。50 Hz 视频中周期较弱且不稳定，强周期窗口占比为 0%–22%，与现场观察一致。

### 4.2 TDMS 没有检出对应的稳定电信号

以 3.10 s 为固定目标，在慢变均值、1 kHz 以下波动包络、全带宽 RMS 和高频残差 RMS 中检验 0.323 Hz。每组阈值由同一探测器、同一实验序列的背景与 VFD STOP 数据生成，为经验零假设的第 95 百分位。

- 30 Hz 工况中，TC1 各特征的通道支持率中位数为 9.1%–18.2%，TC2 为 10%；没有某一特征同时在两台探测器、两次摆位和三个载波设置下持续增强。
- 全部 30 Hz 记录中仅三项单次结果超过 20% 支持率，最高为 `duo1/TC1/sub-kHz RMS` 的 36.4%，但在同组 TC2 和换位实验中没有复现。
- PCA 组合信号在背景或 VFD STOP 中也出现过比 30 Hz 工况更高的 0.323 Hz 峰，因此单独看到该频点峰值不能归因于水流。

**低频最终结论：** 视频和音频能够确认 30 Hz 工况存在约 3.1 s 的水流脉动，但在本次探测距离、传感器和噪声环境下，TDMS 中没有检出可跨通道、跨探测器、跨换位复现的对应低频电信号。实验支持“低频水流电信号低于当前系统的可靠检出能力”，而不是证明该物理信号严格为零。

## 5. VFD 载波实验

### 5.1 RUN 状态造成了强高频线谱干扰

与各探测器的 VFD 上电 STOP 相比，所有有效通道、所有 4/8/12 kHz × 30/50 Hz RUN 工况的高频带功率均增加：

| 探测器 | 1–20 kHz | 20–80 kHz | 80–200 kHz |
|---|---:|---:|---:|
| TC1 | +8.73～+8.77 dB | +18.29～+19.54 dB | +13.55～+15.46 dB |
| TC2 | +18.24～+23.08 dB | +7.29～+22.98 dB | +4.12～+18.71 dB |

每一项的正向通道比例均为 100%。功率主要集中在大量窄谱线上：例如 `20–80 kHz` 中，能量最高的 1% 频点在 RUN 时通常占总带功率约 86%–99.5%，明显高于 STOP 的约 33%（TC2）或 66%（TC1）。因此高频增强不是平坦宽带噪声抬升，而是 VFD/电机运行链产生的密集线谱干扰。

### 5.2 不能把某个峰认定为设定载波

- 在每个 RUN 文件中分别检验 4、8、12 kHz 候选峰，实际设定频率仅在 12 个“探测器×载波×输出频率”组合中的 3 个排名第一。
- 实际设定频点附近的平均谱功率相对局部基线仅约 −0.5～+1.6 dB；峰值大于局部基线 10 dB 的通道支持率为 0%–36%，且不随设定稳定变化。
- 4/8/12 kHz 谐波梳状检验也没有得到稳定的“设定频率最优”结果。
- 视频音轨中 4 kHz 和 8 kHz 文件的最强候选通常仍在约 12 kHz 附近，因此手机/电脑录音不能作为载波频率测量依据。

TC2 中 12 kHz 设置的 `20–200 kHz` 总功率低于 4/8 kHz，且在 30 Hz、50 Hz 下方向一致；但 TC1 未复现这一规律。因此它可记录为 TC2 本次序列中的现象，不能上升为通用载波规律。

**高频最终结论：** 本组数据可以确认“设备由 STOP 进入 RUN 后，VFD—电机—泵运行链显著产生高频窄谱线干扰”；但不能确认某一谱峰就是 4/8/12 kHz 设定载波，也不能仅凭本组数据把干扰进一步唯一归因于 VFD 功率器件而排除电机、电缆和负载共同作用。

## 6. 数据完整性说明

`12k30hz.mp4` 与 `4k50hz2.mp4` 的 SHA-256 完全相同，是同一个视频的重复文件，至少一个名称标注错误。两者已标记为 `duplicate_file=True`，不参与按载波或输出频率的条件判断。

## 7. 本组实验的最终结论

1. 三个持续坏道已被明确定位，后续应固定排除 `TC1-12`、`TC2-8`、`TC2-11`。
2. TC1、TC2 存在频率相关的灵敏度差异，绝对幅值不能直接合并；换位实验支持以“本机相对本机背景”的方式报告效应。
3. 30 Hz 水流确有约 3.1 s 的机械/声学脉动，但当前电信号数据没有检出可复现对应特征。本组低频结论应写为“未检出，且检出上限受当前传感器与环境噪声限制”。
4. RUN 相对 VFD STOP 在两个探测器所有有效通道上均产生显著高频线谱增强，高频干扰来自 VFD—电机—泵运行链的结论成立。
5. 改变 4/8/12 kHz 设置未带来可重复的对应谱峰迁移，因此“已锁定到 VFD 设定载波频率”这一更强结论不成立。
