## 如何使用

- `record_id` 是相对 `raw_root` 的完整路径。相同文件名可能出现在不同目录，不以文件名单独作主键。
- `channels` 记录通道名、NI 通道标识、采样点数、采样间隔和 TDMS 波形时间字段原值。没有重算坏道或将某批坏道规则套到全部文件。
- `detector` 采用批次明确标签（`documented`），或按用户确认的已知采集箱对应关系赋值（`confirmed_chassis_match`）：`cDAQ9188-1855C19 → TC1`、`cDAQ9188-1B5105D → TC2`。遇到未登记的采集箱且无直接 TC 标签，不猜测；已知对应关系与直接标签冲突时，生成脚本报错。
- `condition` 保存已有工况。按用户约定，未另行说明的停机按变频器通电、泵不转处理。5.12 和 0617 的 123 条 0 Hz 记录改标 `STOP`，保留 `output_nominal_hz=0` 和规则来源，不冒充电源状态实测。明确标注的纯背景、开路及其他实验标签不变。11.12 的 `back2/back3/back4` 是通电停机。11.11 三条未确认距离的 B 模式保留名义距离，同时让 `distance_m` 为空。
- 电压、电流、载波和命令时间区分设定值或名义值，不作为同步实际波形。11.17 的有电流标记是整组日志描述；5 kV 是未报告，不是确认零电流。11.10 的电导率 250 没有可靠单位。
- `8.11.2/cp3000near2nottrans/20260811204322.418113-1.tdms` 与 `cp3000near2` 下同名原文件经 SHA-256 核对一致：`7f5ec06b0bf6781443b9df4f6af40eb71e1c47fc960139850d2c9ce5ca717653`。保留两个路径，分析时只算一次，沿用 `cp3000near2` 的工况元数据。未对其余文件做全盘内容去重。

校验：索引的 472 个路径与 D:\Lab 的可见 TDMS 路径逐一对应；文件大小和扫描结果一致；472 份元信息均可读，均为 12 路、400 kSa/s。未读取全量波形，不能以此代替波形完整性或通道健康检查。
