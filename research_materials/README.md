# 研究资料汇总：先舰艇背景，再实验映射

更新：2026-09-28。此处是当前专项资料的统一入口，不是新的论文章节安排。

## 当前顺序

首先阅读[研究链条审查](00_chain_review/研究链条审查与推进依据_20260928.md)：最新要求是以方向、假设和证据连接的审查为主，计算建模服务于明确问题。以下仍从真实舰艇背景入手，但不要求先完成参数不全的复杂艇体模型才允许核查实验与接收链。

1. **真实研究背景：水下舰艇，首先考虑潜艇。** 从腐蚀/防腐回路、轴系调制及运动诱导等源机制出发，整理有出处的尺度、源强、频率与边界条件；先做背景侧理论与COMSOL小模型。
2. **背景侧模型核验。** 分清文献实测、文献仿真、文献量级估算、本文参数化算例。先问舰艇在接收位置产生什么场，再问接收器是否能测到。
3. **随后才映射到实验。** 分别核对电极、水泵/VFD装置、有限水体及空气界面；不将水泵直接视为缩比潜艇，不因现有实验结果较弱而替换掉舰艇背景。

## 整理方式和边界

- 文献、理论程序、理论结果、论文材料、COMSOL说明和阶段报告已物理复制到90_material_snapshot，约60.09 MiB；不是仅做链接。
- 原文件不删除、不移动，避免破坏脚本、论文和仿真引用。原路径仍是历史材料的权威位置；集中副本是本次整理时点的快照，不自动同步。
- 汇报PPT及其输出图片目录不整理、不修改。原始实验数据不复制、不重算。既有大型MPH工程只建立索引。
- 快照保留历史内容原样，其中旧结论、旧“下一步”和假设参数不自动成为当前结论。跨目录链接若依赖未复制的大结果，应按清单返回原路径。
- 跨环节的方向审查写入00_chain_review；新的舰艇背景资料写入01_vessel_background；新的实验映射资料写入02_experiment_mapping。已完成的旧程序不为统一外观而搬家。

## 本轮修正

上轮将背景收敛为“局部电流回路”过早。现恢复为**真实水下舰艇的电学信号背景**。局部源/偶极子仍是数学工具和实验等效对象，不能替代背景本身。

“真实背景”不意味着已取得某型号实艇数据。公开文献允许建立有物理依据的通用潜艇模型，但当前尚不能输出某艘实艇的确定场强或TC探测距离。
