# 阴极保护电极组件三维模型 V1

## 1. 当前范围

本模型只建立照片中的盖板、电极和简化夹持组件，不包含水桶、水域、空气域、直流电源和电学物理场。模型采用局部坐标：盖板下表面附近为 `z=0`，石墨电极沿负 `z` 方向竖直伸入水中；碳钢管沿 `y` 方向横置，便于下一步整体平移到水桶顶部。

模型文件：`models/cathodic_protection_electrode_assembly_3d_v1.mph`。

## 2. 已采用的确认尺寸

| 部件 | 参数 | 当前值 |
|---|---|---:|
| 20号无缝碳钢管 | 主体长度 | 0.40 m |
| 20号无缝碳钢管 | 外径 | 0.10 m |
| 20号无缝碳钢管 | 壁厚 | 3 mm |
| 暴露窗口 | 轴向长度 | 0.20 m |
| 暴露窗口 | 沿管周展开宽度 | 0.12 m |
| 石墨电极 | 直径 | 25 mm |
| 石墨电极 | 暂定长度 | 0.20 m |

碳钢管按空心圆管建立，并在两端保留3 mm封闭端盖。管外增加防水绝缘层，只在朝向石墨的一侧切除20 cm乘12 cm窗口；理论暴露面积为0.024 m²。

碳钢管暴露窗口中心与石墨中心的连线沿局部 `x` 方向。碳钢管绕这条连线旋转90度后横置，因此碳钢管轴线与竖直石墨轴线垂直，而暴露窗口仍保持正对石墨。

## 4. 已定义材料

- 碳钢试样：20号无缝碳钢，暂用电导率 `6.0e6 S/m`。
- 石墨电极：暂用电导率 `1.0e5 S/m`。
- 圆盖和方形支撑板：PE等效材料。
- 管外防水胶带：绝缘材料，暂用相对介电常数3.2。

上述电导率只作为后续电场模型的初始材料值，不包含电极极化、交换电流密度和电化学动力学。

## 5. 下一步合并前仍需确认

1. 石墨棒实际有效长度及是否整段裸露。
2. 碳钢窗口相对石墨棒的准确朝向。
3. 两电极中心距离和各自距桶盖中心的位置。
4. 钢管、石墨棒顶部到盖板下表面的实际距离，以及160–180 L水位下的浸没长度。
5. 直流电源是恒流还是恒压、设定值、纹波频率和纹波幅值。
6. 碳钢接电源负极、石墨接正极的阴极保护极性是否与现场接线一致。
7. 电源外壳、负端与建筑PE是否浮置、单点接地或直接接地。

这些参数确认后，再把组件放入整体水桶模型，并分别建立直流稳态、电源纹波频域和外部空气电场工况。
