## 1. 建模目标

建立水桶、水体、循环泵、变频器、电源、连接管路及外部空气的三维 COMSOL 模型，分别研究以下四类源对外部电场的贡献：

1. 水体流动产生的电势或等效电流源。
2. 泵及电机产生的电场源。
3. 变频器产生的工频、输出基波、PWM 开关及共模电场源。
4. 电源及供电线路产生的工频、纹波或开关电场源。

目标输出包括三维外部电场分布、指定位置的时域波形、频域谱、各源单独贡献及四源叠加结果。

## 2. 坐标系约定

- 采用右手直角坐标系。
- 水桶轴线中心为平面原点 `(x, y) = (0, 0)`。
- 地面为 `z = 0`。
- 俯视时泵位于水桶右侧，定义为 `+x` 方向。
- 观察点位于水桶下方，定义为 `-y` 方向。
- 水桶中心的具体 `z` 坐标将在明确桶底离地高度后确定。

暂定设备平面位置：

| 对象 | 暂定坐标 | 说明 |
|---|---:|---|
| 水桶中心 | `(0, 0)` | 平面坐标原点 |
| 泵中心 | `(+x_pump, 0)` | 已确认 `0.5 m` 指下部直管长度，不是桶与泵中心距；中心坐标待实测 |
| 变频器中心 | `(+x_pump+1.5 m, 0)` | 位于泵右侧约 1.5 m，与墙上 380 V 供电位置归为同一源区 |
| 380 V 墙上电源 | `(+x_pump+1.5 m, 0)` | 具体墙面高度和电缆出口位置待确认 |
| 观察点 P2 | `(0, -2.0 m, 1.0 m)` | 已确认距地面 1 m |
| 观察点 P3 | `(0, -3.0 m, 1.0 m)` | 已确认距地面 1 m |
| 观察点 P4 | `(0, -4.0 m, 1.0 m)` | 已确认距地面 1 m |

## 3. 水桶与水体

### 3.1 已知参数

| 参数 | 数值或描述 |
|---|---|
| 类型 | 200 L 水塔/水桶 |
| 材料 | PE 牛筋料 |
| 总高度 | 0.87 m |
| 垂高 | 0.72 m |
| 外径 | 0.56 m |
| 标称容积 | 200 L |
| 实际水量 | `160-180 L` |
| 安装方式 | 水桶直接置于地面；现场照片可见桶外有铝型材限位/支撑框架 |
| 桶壁厚度 | 未知，第一版暂按参数化厚度处理 |

按直径 `0.56 m`、直筒高度 `0.72 m` 估算，直筒圆柱容积约为 `177 L`；结合顶部、底部曲面后与标称 `200 L` 基本一致。因此第一版几何可采用“圆柱直筒 + 简化弧形顶底”。

### 3.2 上部入口

- 位于水桶上方。
- 平面位置距桶圆心约为水桶半径的 `2/3`。
- 水桶半径为 `0.28 m`，因此入口中心距轴线约 `0.187 m`。
- 桶体内接一个一寸内外丝接头。
- 外接 DN40 法兰。
- 法兰连接橡胶高压钢丝胶管。
- 上部胶管长度约 `2 m`。
- 上部胶管向上并向右弯曲，最终连接泵右侧法兰。
- 上部管路作为泵的回水/放水口。

### 3.3 下部出口

- 与上部入口处于同一竖直平面或相同方位角，具体含义待确认。
- 接口中心距地面约 `0.10 m`。
- 直接连接 DN40 法兰。
- 使用同类型橡胶高压钢丝胶管。
- 下部胶管长度约 `0.50 m`，基本水平直线连接泵左侧法兰。
- `0.50 m` 已确认是下部管长，不是水桶与泵的中心距。
- 上下胶管均为两端自带法兰；一端接泵，另一端通过转接件接水桶。

### 3.4 循环方向

- 泵从水桶下部抽水。
- 泵向水桶上部回水。
- 形成闭式循环管路。

## 4. 循环泵与电机

| 参数 | 数值 |
|---|---:|
| 流量 | `6.3 m^3/h` |
| 扬程 | `32 m` |
| 配用功率 | `2.2 kW` |
| 额定功率 | `2.2 kW` |
| 转速 | `2800 r/min` |
| 额定电压 | 三相 `380 V` |
| 额定电流 | `4.58 A` |
| 效率 | `85.9%` |
| 功率因数 | `0.85` |

推导参数：

- 额定流量约为 `1.75 L/s`。
- 若 DN40 实际内径按 `40 mm` 估算，管内平均流速约为 `1.39 m/s`；最终应使用胶管真实内径重新计算。
- 机械转频约为 `46.67 Hz`。
- 三相视在功率约为 `3.01 kVA`。
- 按功率因数计算的输入有功功率约为 `2.56 kW`，与 `2.2 kW / 85.9%` 基本一致。

## 5. 变频器

| 参数 | 数值 |
|---|---:|
| 额定功率 | `3.7 kW` |
| 输入 | 三相 AC `380 V`，`10.5 A`，`50/60 Hz` |
| 输出 | 三相 AC `380 V`，`9 A`，`0-630 Hz` |
| 负载 | 2.2 kW 循环泵电机 |

变频器对外电场通常包含：输入工频、直流母线纹波、输出基波、PWM 开关频率及其边带、共模电压和电缆辐射。当前实际运行频率和 PWM 开关频率未知，后续可从变频器参数菜单、型号说明书或实测波形获得。

## 6. 电源

- “电源”已确认为墙上的三相 `380 V` 工频供电电源。
- 电源源应建模为墙上供电端、墙到变频器的三相电缆及保护地回路，而不是单独的电子电源模块。
- 仍需确认墙上出线点高度、电缆长度和路径、是否有中性线、保护地接法。

## 7. 管路与连接件

已知组成：

- 一寸内外丝接头。
- DN40 法兰。
- 橡胶高压钢丝胶管。
- 下部管路约 `0.50 m`，直连泵左侧。
- 上部管路约 `2 m`，弯曲连接泵右侧。
- 两根胶管均两端带法兰，通过转接件接水桶。

钢丝胶管中的金属增强层可能形成屏蔽、感应电流和接地通路。法兰机械连接方式已经明确，但钢丝增强层是否与两端法兰电气导通仍需测量，不能仅从机械连接判断。

## 7.1 现场照片确认的信息

- 泵为立式电机、卧式进出水结构，左侧接水桶下部抽水管，右侧接上部回水管。
- 下部管路近似水平直线，上部管路存在明显的竖直抬升和弯曲段。
- 泵安装在木质底座/托板上，水桶周围有铝型材框架。
- 设备位于带大面积金属栏杆和金属门窗框的区域，附近还有实验台架和导线。
- 金属栏杆、门窗框和铝型材会改变外部电场边界。第一版可忽略远处细节，精细版需按实测位置加入主要金属结构。

## 8. 第一版推荐模型结构

1. 三维几何：水桶、水体、上下接口、两根胶管、泵等效外壳、变频器外壳、电源/配电箱、主要电缆、地面及空气域。
2. 流体模型：入口/出口闭式循环，稳态流量 `6.3 m^3/h`，得到水体和管内速度场。
3. 水流电源：先采用参数化等效流动电流密度；获得 pH、ζ 电位等参数后再做电动流耦合。
4. 泵源：第一版使用电机等效三相电流、等效电偶极子和电流环，不精细绘制绕组槽。
5. 变频器源：输入工频端口、输出三相 PWM/频谱及共模源。
6. 电源源：根据实际类型采用工频端口或开关电源频谱。
7. 开放空气边界：采用无限元或 PML，不使用现有二维工程中的封闭 PEC 外边界。
8. 结果探针：在 P2、P3、P4 记录 `Ex`、`Ey`、`Ez` 和 `|E|` 的时域与频域结果。

## 9. 仍需补充的参数

### 9.1 第一优先级：决定模型能否开始

- `0.87 m` 总高和 `0.72 m` 垂高分别对应桶体哪一段；桶底曲面和顶盖的大致高度。
- `160 L`、`170 L` 还是 `180 L` 作为基准工况，或是否三个水位都要扫参。
- 水桶中心到泵轴线中心的水平距离 `x_pump`。
- 泵的外形尺寸、左右法兰中心高度、泵体宽度和电机高度。已有现场外形照片，仍建议用卷尺补四个尺寸。
- 胶管实际内径、外径；上部胶管主要折点的高度和水平位置。
- 变频器实际运行输出频率，而不是允许范围 `0-630 Hz`。
- 变频器 PWM 开关频率。
- 变频器至泵的三相电缆长度、线径、芯线排列、是否屏蔽。
- 需要分析的最高频率，例如 `100 kHz`、`1 MHz`、`10 MHz` 或更高。

### 9.2 第二优先级：决定电场幅值是否可信

- 水的实测电导率已确认为 `500 uS/cm = 0.05 S/m`。
- 水温、pH、主要离子或水质类型。
- PE 桶壁厚度及准确材料牌号。
- 一寸接头和 DN40 法兰的材质。
- 钢丝胶管的钢丝编织/缠绕结构，以及钢丝是否与两端法兰导通。
- 泵壳材质及是否接保护地。
- 变频器外壳材质、安装高度和接地方式。
- 墙上 380 V 出线端位置、供电电缆路径和保护地连接方式。
- 水桶、泵、变频器、电源是否共用同一保护地。
- 地面材料：土地、混凝土、环氧地坪或金属平台。

### 9.3 强烈建议提供的实测数据

- 变频器输出三相线电压或相电压的示波器 CSV。
- 变频器共模电压或保护地电流波形。
- 泵运行时三相电流波形。
- 电源输出纹波或供电端电压波形。
- 观察点处现有电场传感器的时域波形或频谱，用于校准等效源。

## 10. 当前关键假设与待确认项

- `0.5 m` 已按下部管长处理，泵中心坐标等待补测。
- 变频器及墙上电源源区位于泵右侧约 `1.5 m`，其绝对坐标随泵中心坐标确定。
- 三个观察点按 `(0,-2,1)`、`(0,-3,1)`、`(0,-4,1)` 处理。
- 上下接口暂按同一方位角处理。
- DN40 暂按 `40 mm` 内径估算，实际胶管内径待测量。
- 水电导率采用 `0.05 S/m`。
- 水流电场、泵电场、变频器电场和电源电场先分别求解，最后按实际相位或实测波形叠加。
