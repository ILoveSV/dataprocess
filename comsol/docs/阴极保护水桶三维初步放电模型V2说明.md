# 阴极保护水桶三维初步放电模型 V2

## 1. 模型范围

本模型把已确认的阴极保护电极组件安装到直径0.56 m、高0.87 m的PE水桶顶部，并建立170 L水域中的三维直流放电基线。碳钢管沿水平方向布置，暴露窗口正对竖直石墨电极，两电极中心距暂为0.30 m。碳钢管和石墨有效段均完全浸入水中。

模型文件：`models/cathodic_protection_tank_3d_preliminary_v2.mph`。

## 2. 当前物理模型

- COMSOL物理场：电流（Electric Currents）。
- 研究类型：稳态直流。
- 控制方程：`div(J)=0`、`J=sigma*E`、`E=-grad(V)`。
- 石墨边界：总电流端子，暂定输入10 mA。
- 碳钢边界：只有与水接触的暴露窗口作为0 V参考阴极。
- PE桶壁、水面、胶带和绝缘支架：电绝缘边界。
- 水体电导率：暂将“500”解释为500 µS/cm，即0.05 S/m。

本版本只计算水体内的欧姆导电，不包含电极极化、电荷转移动力学、双电层、电解产气、浓差极化、温升、水流和电源纹波。

## 4. 初步结果

| 指标 | 结果 |
|---|---:|
| 石墨端电压 | 0.74967 V |
| 等效水路电阻 | 74.967 ohm |
| 欧姆功率 | 7.4967 mW |
| 水域平均电势 | 0.35789 V |
| 水域平均电场强度 | 0.53453 V/m |
| 水域平均电流密度 | 0.026727 A/m^2 |
| 水域最大电场强度 | 124.70 V/m |
| 水域最大电流密度 | 6.2352 A/m^2 |

最大电场和最大电流密度位于电极及窗口边缘，受理想尖角和局部网格影响明显。本版本应优先使用端电压、等效电阻、整体电势分布和远离边缘的场值；边缘最大值需要圆角、局部加密和网格收敛验证后才能用于定量比较。

## 5. 下一轮需要替换的真实数据

1. “电导率500”的准确单位、测量温度和仪表读数。
2. 直流电源采用恒流还是恒压，以及实际设定电流、电压和限流值。
3. 实测稳态电流与两电极端电压随时间的数据。
4. 石墨实际直径、有效浸水长度和裸露范围。
5. 两电极实际中心距、距水面深度和窗口精确朝向。
6. 碳钢窗口的真实裸露面积、边缘胶带形状及是否存在漏水裸露区。
7. 若要计算真实阴极保护电位，需要碳钢和石墨在该水质中的极化曲线，或至少开路电位、Tafel斜率和交换电流密度。

获得前六项后即可先校正欧姆模型；获得第七项后再升级为二次电流分布或电化学动力学模型。
